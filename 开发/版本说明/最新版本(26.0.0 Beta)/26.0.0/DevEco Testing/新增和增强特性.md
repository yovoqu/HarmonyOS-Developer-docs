##### DevEco Testing 26.0.0 Beta1（26.0.0.300）

 
- 稳定性检测能力增强：支持指定入口定向激发稳定性问题，提供覆盖更全的内存泄漏检测能力。
- UX检测支持直板机、折叠屏多设备布局对比检测。
