# 变更说明

更新时间：2026-06-27 01:41:31

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/ide-changelogs-610

#### DevEco Studio 6.1.0 Release引入的变更



#### 编辑器新版本暂不支持C API兼容性告警的Quick Fix功能

从DevEco Studio 6.1.0 Release（6.1.0.850）版本开始，DevEco Studio不支持Quick Fix自动快速修复C API兼容性告警。

**变更影响**

如用户编写如下代码：

工程级build.profile.json5配置为，"compatibleSdkVersion": "5.1.1(19)",

同时，用户使用API 20的接口。

```text
#include <ohaudio/native_audio_stream_manager.h>

void test()
{
    OH_AudioStreamManager_IsFastPlaybackSupported(nullptr, nullptr, AUDIOSTREAM_USAGE_UNKNOWN);
}
```

此时，老版本存在C API兼容性告警和使用APIAVAILABLE的Quick Fix能力。


![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/i6oYoIM3QVCS9sgRYPYE1w/zh-cn_image_0000002603735633.png?HW-CC-KV=V1&HW-CC-Date=20260701T015236Z&HW-CC-Expire=86400&HW-CC-Sign=20ED2E63E6E0A8434D7A4D7D8EE70A98FB6C7666A939F0135F6FDB5FE45EE541)


新版本保留C API告警，去掉自动修改代码的Quick Fix功能，并新增指导文档跳转链接。


![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/tB9x4Sp3QECXnlOdORDeSA/zh-cn_image_0000002603737439.png?HW-CC-KV=V1&HW-CC-Date=20260701T015236Z&HW-CC-Expire=86400&HW-CC-Sign=1D8F6810FC2C47ED310448FBCD9F23753DDE88AAE238C71BBD821BC817C24496)


**适配指导**

参考[CAPI兼容性保护高阶用法](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/c-api-compatibility-warning)手动进行告警修复。



#### Hvigor新版本修改为不支持自动传递COMPATIBLESDKVERSION参数给编译器

从DevEco Studio 6.1.0 Release（6.1.0.850）版本开始，DevEco Studio不自动传递 "arguments": "-DOHOS_COMPATIBLE_SDK_VERSION=x.x.x" 参数给cmake，不默认开启弱引用功能 。

**变更影响**


![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/_fiZecXERWOEkkWPfIhV8Q/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T015236Z&HW-CC-Expire=86400&HW-CC-Sign=1E54111E8F9175D08602268616A79E25E72791EEBABA5034B18854F724E6E2E5)


在DevEco Studio版本：6.1.0.830(API 23 Release) 上使用了C API兼容性保护，如果在高版本需要继续使用，必须参考[CAPI兼容性保护高阶用法](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/c-api-compatibility-warning)的步骤重新配置。



**适配指导**

参考[CAPI兼容性保护高阶用法](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/c-api-compatibility-warning)步骤重新配置。
