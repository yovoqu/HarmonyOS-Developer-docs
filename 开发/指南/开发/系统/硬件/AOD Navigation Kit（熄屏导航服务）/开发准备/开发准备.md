# 开发准备

更新时间：2026-07-28 11:23:46

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/aodnavigation-preparations

#### 基本准备工作

请先参考“[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)”完成基本准备工作后再继续进行以下开发活动。
 
  

#### 开通熄屏导航服务

使用熄屏导航功能需要先开通熄屏导航服务，具体请参见下方开通熄屏导航服务步骤。
 1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“开发与服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/cF0uJy-mQNSVP2uPK-NvFA/zh-cn_image_0000002686086595.png?HW-CC-KV=V1&HW-CC-Date=20260730T072204Z&HW-CC-Expire=86400&HW-CC-Sign=5FDA979E0B37988B8AC2DE7E4AACDA91FCF26F120DBA4A376BDB0F45F64AC1EF)

2. 在项目列表中找到需要开通服务的应用。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/2ybfWVZWSVa2Yi-TITVlnw/zh-cn_image_0000002685926767.png?HW-CC-KV=V1&HW-CC-Date=20260730T072204Z&HW-CC-Expire=86400&HW-CC-Sign=C7531D4E88810479AC79C4611D7E54FDC613DA2DED60724EAF4253B8F9C3D9BF)

3. 进入“开放能力管理”页签，找到“熄屏导航服务”，点击“申请”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/HQM26Rz2SNiRiyj6PNvxpA/zh-cn_image_0000002656007088.png?HW-CC-KV=V1&HW-CC-Date=20260730T072204Z&HW-CC-Expire=86400&HW-CC-Sign=FBBF4C541B7717F927444046BE627CA8B2ED3EC511F9729031098A8E4AD47992)

4. 确认您已满足开通熄屏导航服务的所有条件后，点击“下一步”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/sbt8PsUeRA-0KHJAhTKofg/zh-cn_image_0000002655847168.png?HW-CC-KV=V1&HW-CC-Date=20260730T072204Z&HW-CC-Expire=86400&HW-CC-Sign=61585A9CA9347FDE40EFEE2547623743FDBD4A12AFB0B333ABD071DC0E81089E)

5. 填写熄屏导航服务申请相关参数。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/I4qQ5FhMR_qsez7Qw3RKng/zh-cn_image_0000002686086597.png?HW-CC-KV=V1&HW-CC-Date=20260730T072204Z&HW-CC-Expire=86400&HW-CC-Sign=BE13EAB117E9877B564CC49B892A40DFAC1D67EB361E2FA8549BEAA983664F0B)


  
> [!TIP]
> “申请原因”一栏填写要求如下： 应用介绍 ：说明应用类型，例如：XXX应用属于XXX类型的应用。 使用场景 ：说明权限使用场景，例如：在XXX场景下，需要使用XX能力。 申请用途 ：描述该权限的用途，例如：用户使用XXX功能后，进行XXX操作，提供XXX服务。 场景使用承诺： 需补充填写以下承诺内容“承诺仅在获批场景内使用该能力，如超范围使用，华为有权收回该能力。"。

6. 系统将推送消息到互动中心，请等待审核。3个工作日内审核结果会通过站内消息的形式发送到[互动中心](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive)，审核通过后，熄屏导航服务默认勾选生效。
