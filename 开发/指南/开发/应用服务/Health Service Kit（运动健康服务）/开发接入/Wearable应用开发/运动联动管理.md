# 运动联动管理

更新时间：2026-07-28 11:23:46

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/health-litewearable-sport-linkage-manage

#### 场景介绍

从6.1.1(24) 版本开始，支持运动联动管理。

运动联动管理包含运动联动的配置、开启、暂停、恢复、停止，数据订阅、取消订阅和下发融合数据，以及锻炼记录的读写。



#### 接口说明

| 接口名 | 描述 |
| --- | --- |
| config(workoutConfig: WorkoutConfig): void | 运动联动配置。 |
| start(): StartResult | 开启运动联动。 |
| pause(): void | 暂停运动联动。 |
| resume(): void | 恢复运动联动。 |
| stop(): void | 停止运动联动。 |
| onData(dataType: undefined, listener: Callback<SampleReal[]>): void | 订阅所有类型的数据。 |
| offData(dataType: undefined, listener?: Callback<SampleReal[]>): void | 取消订阅所有类型的数据。 |
| sendData(sampleReal: SampleReal[]): void | 下发融合数据。 |
| readData<T extends ExerciseSequence>(request: exercisesequencereadrequest, callback: Callback<T[]>): void | 读取最新一条锻炼记录。 |
| saveData(exerciseSequence: ExerciseSequence): void | 保存锻炼记录。 |




#### 开发前检查

 - 完成[申请运动健康服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/health-apply)。
 - 需先通过[用户授权](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/health-litewearable-add-permissions)接口引导用户授权，用户授权应根据[权限说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/health-permission-description#lite-wearable)中要求来打开锻炼记录读/写和联动接口控制权限，。
 - 常见问题请参考[Health Service Kit常见问题](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/health-faqs)。




#### 开发步骤
1. 导入运动健康服务功能模块。

  
```text
import healthService from '@hms.health.service';
import healthStore from '@hms.health.store';
```

2. 配置联动。

  
```text
function config() {
  let workoutOptions = {
    linkageType: healthService.workout.LinkageType.ACTIVITY_LINK,
    sportType: healthStore.exerciseSequenceHelper.badminton.EXERCISE_TYPE.id,
    activityGoals: [
      {
        type: healthService.workout.TargetType.CALORIE,
        value: 100
      }
    ]
  };
  try {
    healthService.workout.config(workoutOptions);
  } catch (err) {
    // 异常场景处理
  }
}
```

3. 开启联动。

  
```text
function start() {
  try {
    let startResult = healthService.workout.start();
  } catch (err) {
    // 异常场景处理
  }
}
```

4. 暂停/恢复联动。

  
```text
function pause() { // 暂停联动
  try {
    healthService.workout.pause();
  } catch (err) {
    // 异常场景处理
  }
}

function resume() { // 恢复联动
  try {
    healthService.workout.resume();
  } catch (err) {
    // 异常场景处理
  }
}
```

5. 订阅数据，可以实时获取运动数据，并对获取的运动数据进行处理。

  
```text
function onData() {
  const callback = (sampleReals) => {
    // 运动数据回调处理流程
  };

  try {
    healthService.workout.onData(undefined, callback);
  } catch (e) {
    if (e.code === 1009104001) { // 联动已开启其他应用已调用start开启联 动
      // 回到准备界面
    } else if (e.code === 1009104003) { // 在当前状态下，指令非法。请先 开启运动联动
      // 回到准备界面
    }
  }
}
```

6. 下发融合数据（根据需求调整调用时机）。
