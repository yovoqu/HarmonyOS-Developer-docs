#### 创建Wallet Kit服务

请先参考“[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)”完成基本准备工作和指纹配置，再继续以下开发活动。
 1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“开发与服务”。

2. 选择对应项目。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/ML3oYKapShqzw-i1SUMI8g/zh-cn_image_0000002656007880.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=AD9340F86542F50EC686CC48ADE54A0C70C0450137AD837DF1B9BBE4B42D51FC)

3. 选择“钱包服务”，点击“申请服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/h5vWA9yYQbCJl9GWMb_C6A/zh-cn_image_0000002656007882.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=6F92103F649F773EB2DA15FEF79BF6AC86FDE65DB4A4C58C99C89E6CF7A5F07A)

4. 点击“点击申请”，并选择新版本。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/myPu2pBLQRGf-2Egqu01zA/zh-cn_image_0000002655847962.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=2841BA8E94469DC9DE49B0717DD6B6C43AADA7FF85188E728DE48242FD4D1E09)


  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/OJSzHAfGTlW1cKKzais92Q/zh-cn_image_0000002656007892.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=EB9AFB6A1EF0597F9A0C977AB59EE90B599720BA0E944328EEA971AF0FF01BDD)

5. 配置Wallet Kit服务参数：服务类型选择票，服务子类型选择通用凭证，服务项目按需选择，并指定服务号、开发者服务公钥及开发者云侧服务地址前缀后，点击“下一步”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/mNoP806kRvmA1neuXD3RPg/zh-cn_image_0000002655847972.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=3D5B1C99A1454A1EC3787E91892E2EABD9E2B50797A17300BB56F5BFC4639712)


| 参数 | 说明 |

| --- | --- |

| 服务名称 | Wallet Kit首页列表展示该开发者所有创建的服务时，服务名称用于区分不同的服务。建议命名为公司简称+Wallet Kit+应用场景，长度不超过64个字符。 |

| 服务类型 | 固定选择“票”。 |

| 服务子类型 | 固定选择“通用凭证”。 |

| 服务项目 | 选择接入的服务项目。 |

| 默认卡名称 | 在钱包内显示的默认卡名称，长度不超过64个字符。 |

| 服务号 | 开发者服务号，用于区分不同的项目和服务。建议格式为【hwpass.公司简称.项目名称.pass.服务项目】，须以hwpass开头 (自动填充，无需输入)，可为数字、字母，长度不超过32个字符。 |

| 服务公钥 | 开发者将生成的公钥，后续该公钥将作为Wallet Kit服务器认证开发者身份的凭证。 |

| 服务器地址前缀 | 开发者服务器地址，用于Wallet Kit服务器在开卡或删卡成功后回调开发者。如果不需要回调结果，可以不填该字段。 |
6. 配置NFC&二维码参数：按需选择卡片激活设备限制，可展码通行，但不涉及NFC，默认在用户华为账号登陆的所有设备可见，不支持动态二维码，推荐配置如下。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/mPJRI0uxT-uaKA-aWeIL7g/zh-cn_image_0000002655848002.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=DA55C8D97B664FAABBBC73BCAF3FD36541042AC0A39FACD59D465B11CCCAA954)

7. 配置添加预览信息：按要求上传卡面底图。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/HfRX5OlYTXmPH_YVCuchyg/zh-cn_image_0000002686087431.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=2AB11EE27D1B3B609E49B499CCEB3BD4D77E23073E04F5EE28228D3B011B6E2B)

8. 配置卡详情页信息：按需配置卡面个性化信息，功能区，运营区以及官方App/元服务跳转。

  基本信息配置：可指定背景色、字体颜色、LOGO等，并输入样例信息查看实际通用凭证的效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/6TkJRHF_Tse8bK74CT53bA/zh-cn_image_0000002685927603.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=8272C69BB7A2B24DB648D4394CB930650C3359446663C0C81528A4C1A23D0E68)


  主要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/WMVgjA5bRhqugHf_6xAjFw/zh-cn_image_0000002656007916.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=4AE0EC5E01EE9C8CE9DBD36EEA68013B3125CC09E5A1D0B2CFA0DDE1B9186AD2)


  次要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/VezbDhfMSI20bPWMYJd-aQ/zh-cn_image_0000002655847996.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=54B139EDF36E6FB693AF7E7FEC5A5DD0437E98E736D229FA327AD44CB387B026)


  功能区配置：支持卡片信息和删除功能。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/YkWUYuWgS5-b9WK5qJlQ_Q/zh-cn_image_0000002685927597.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=020FE8727A05CFB9179C886255C73349D248D6F8142940DC20F7573D5DCED2BB)


| 参数 | 说明 |

| --- | --- |

| 卡片信息 | 用于展示卡面提供服务方（按需配置多语言）信息，按需勾选卡号和联系客服（客服电话方便用户联系）。在详情页点击卡面信息会跳转卡面信息展示。右边可以看到预览效果。 |

| 删除 | 用于控制钱包内删卡。 |

  运营区配置：可以按需配置服务菜单（最多支持5个），按需配置是否提供使用记录查看链接以及华为服务号入口，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/pSL5WQYXSWGTDILu8fpvXA/zh-cn_image_0000002656007918.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=9723B37B3A5F73B8554B7C6D670A9D84866F08A5DB2E5F950A619DF1868B715E)


| 参数 | 说明 |

| --- | --- |

| 服务菜单 | 用于控制详情页的运营区。如果需要配置，点添加按钮后需要配置菜单名称（多语言可选）以及跳转地址。 |

| 是否提供使用记录查看链接 | 用于控制详情页的运营区是否展示使用记录。 |

| 是否提供华为服务号入口 | 控制详情页的运营区的服务号是否展示，如果需要配置，则填写开通服务号的ID和名称。 |

  官方App/元服务跳转配置：按需配置官方App/元服务跳转，如果选择是，需要按需配置跳转链接，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/ZbKj402zSFW5A3v23UVmQQ/zh-cn_image_0000002655847998.png?HW-CC-KV=V1&HW-CC-Date=20260730T072212Z&HW-CC-Expire=86400&HW-CC-Sign=053CEB89AD9D35B1966CC430DC39BA221453C9BE8501C857CD7373BD98D7FC66)

9. 提交前进行信息核对及预览，确认无误后，点击“提交”完成通用凭证Wallet Kit服务接入配置。
