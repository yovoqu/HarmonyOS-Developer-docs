#### 创建Wallet Kit服务

请先参考“[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)”完成基本准备工作和指纹配置，再继续以下开发活动。
 1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“开发与服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/HOWCyL6mQKudGCi88uPI4g/zh-cn_image_0000002685927559.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=EF8410F8F264745AB2A4E5C21BD761CBBBC168290ADF14698FDDC0FAA1492325)

2. 选择对应项目。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/gWrQ9d0BQUyy0C4SGktTFA/zh-cn_image_0000002656007880.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=D15069911C291CC2DC5B5D469C0146F2F698E4035DD684C64EB3446109E18791)

3. 选择“钱包服务”，点击“申请服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/DCFlTaEGTzOw1HadB2XVGA/zh-cn_image_0000002656007882.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=8F5CEB84C2A937961F911B3E73B13F468A3A883214596DEEC2356D3A0F0EFFAF)

4. 点击“点击申请”，并选择新版本。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/qGCj5c3_Q92Xi9r4QrpXHA/zh-cn_image_0000002655847962.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=B45B94938405C305E8A76621DC835A6C895266F3B30FDCE9A7D60B115F056056)


  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/bOzEYDaHQ8GvXl8ZYUwoeA/zh-cn_image_0000002656007892.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=DD19A9EC4F3275F2DD58E8FFB8AA89BC5B6735E0C099627ABCAA85F31DCA6A10)

5. 配置Wallet Kit服务参数：服务类型选择票，服务子类型选择出行凭证，服务项目按需选择，并指定服务号、开发者服务公钥及开发者云侧服务地址前缀后，点击“下一步”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/Gq5ct0aMSE6g2tnyCBm9mA/zh-cn_image_0000002655847972.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=8E70BD3ACD867771C386FD51ACE722255B6779B5E004EBCBEE09A4BBD13471C1)


| 参数 | 说明 |
| --- | --- |
| 服务名称 | Wallet Kit首页列表展示该开发者所有创建的服务时，服务名称用于区分不同的服务。建议命名为公司简称+Wallet Kit+应用场景，长度不超过64个字符。 |
| 服务类型 | 固定选择“票”。 |
| 服务子类型 | 固定选择“出行凭证”。 |
| 服务项目 | 选择接入的服务项目。 |
| 默认卡名称 | 在钱包内显示的默认卡名称 ，长度不超过64个字符。 |
| 服务号 | 开发者服务号，用于区分不同的项目和服务。建议格式为【hwpass.公司简称.项目名称.pass.服务项目】，须以hwpass开头 (自动填充，无需输入)，可为数字、字母，长度不超过32个字符。 |
| 服务公钥 | 开发者将生成的公钥，后续该公钥将作为Wallet Kit服务器认证开发者身份的凭证。 |
| 服务器地址前缀 | 开发者服务器地址，用于Wallet Kit服务器在开卡或删卡成功后回调开发者。如果不需要回调结果，可以不填该字段。 |
6. 配置NFC&二维码参数：可展码通行，但不涉及NFC，默认在用户华为账号登陆的所有设备可见，不支持动态二维码，推荐配置如下。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/x73I1HMKS4ethgnr5Jah6g/zh-cn_image_0000002655847994.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=8F592C7D866B4FE54BA0CFA6430A55E574B4C55461128B06A52998D614D8458A)

7. 配置添加预览信息：按要求上传卡面底图。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/gzhdvcPUQcaL0iAUTfYDpg/zh-cn_image_0000002686087423.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=45B277BE6E139F411D9DEE76AC2A764AEB688C260BEF6E1CC54064DD832381F0)

8. 配置卡详情页信息：按需配置卡面个性化信息，功能区，运营区以及官方App/元服务跳转。

  基本信息配置：可指定背景色、字体颜色、LOGO等，并输入样例信息查看实际出行凭证的效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/eyShI2xjQC2cuNtWv_EYVQ/zh-cn_image_0000002685927595.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=D74685C4F95545DF163AC6FA3BB06F585A0B72A71EA932D36E20EBC4BC89E734)


  主要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/cNbNkeD3Qpa0dF-sRsIK7g/zh-cn_image_0000002656007916.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=6611F7BA37F6DB66AB1D5BD6338E18466F13FF2131EE3FE50F94DF20EA2588C0)


  次要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/uWTCwblKS1qjnC1RnUPEAQ/zh-cn_image_0000002655847996.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=0FD4EC6B25CE487E4A7D70A996B1C166709FD0F465890C2317723A54F69C0D90)


  补充信息区配置：该区域不展示标签，仅展示内容。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/MM8PgYbhQ3KcH2Vnr5D4mQ/zh-cn_image_0000002686087425.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=84D86BDB298DA2F636A2AE82F91710DAEA263A76031DF50E34269DA9252E1545)


  功能区配置：支持卡片信息和删除功能。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/nh2e2Hf4Rb6E8HRR5wNgyA/zh-cn_image_0000002685927597.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=61DCA8C8D64F085B4918E61BA49128518C705B74963CB6850EFBA7F2D5DF5E9A)


| 参数 | 说明 |
| --- | --- |
| 卡片信息 | 用于展示卡面提供服务方（按需配置多语言）信息，按需勾选卡号和联系客服（客服电话方便用户联系）。在详情页点击卡面信息会跳转卡面信息展示。右边可以看到预览效果。 |
| 删除 | 用于控制钱包内删卡。 |

  运营区配置：可以按需配置服务菜单（最多支持5个），按需配置是否提供使用记录查看链接以及华为服务号入口，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/YTvrx4HpSHGsf1mOJG-HHA/zh-cn_image_0000002656007918.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=3CD249C255E1BBD3BD00DF9655D8698A987E33786D7CE84811FAA034478BE2F2)


| 参数 | 说明 |
| --- | --- |
| 服务菜单 | 用于控制详情页的运营区。如果需要配置，点添加按钮后需要配置菜单名称（多语言可选）以及跳转地址。 |
| 是否提供使用记录查看链接 | 用于控制详情页的运营区是否展示使用记录。 |
| 是否提供华为服务号入口 | 控制详情页的运营区的服务号是否展示，如果需要配置，则填写开通服务号的ID和名称。 |

  官方App/元服务跳转配置：按需配置官方App/元服务跳转，如果选择是，需要按需配置跳转链接，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/3Zlfh6rISCm9SA5Tb2tC0w/zh-cn_image_0000002655847998.png?HW-CC-KV=V1&HW-CC-Date=20260730T072210Z&HW-CC-Expire=86400&HW-CC-Sign=9B0CFD4E4BACB4C65C64C64D3F48805ACC16B1A81835A6E15A2993AE5574004F)

9. 提交前进行信息核对及预览，确认无误后，点击“提交”完成出行凭证Wallet Kit服务接入配置。
