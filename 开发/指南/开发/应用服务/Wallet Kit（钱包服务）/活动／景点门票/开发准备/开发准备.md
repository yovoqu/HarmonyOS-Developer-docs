#### 创建Wallet Kit服务

请先参考“[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)”完成基本准备工作和指纹配置，再继续以下开发活动。
 1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“开发与服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/ZPi5cYoBQvGyz59yfJEyEQ/zh-cn_image_0000002685927559.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=91CA4BA1239E1AABD081FB6405FB11F19BF2BE6E56855C720C41E6E2CA5F5572)

2. 选择对应项目。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/l4Cwkz_URxOmA7xVCo28YA/zh-cn_image_0000002656007880.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=315B63C642A45015C325105219F1E87F2E21DA795F2F0F45CA4ADF62A85E5EC6)

3. 选择“钱包服务”，点击“申请服务”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/G5ABrOVfSuWu_jWUy8fKow/zh-cn_image_0000002656007882.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=FB14B91152B99427BF0EA69BA29E69CA389EEE063AF6FAFD6B4E5E024001D4D2)

4. 点击“点击申请”，并选择新版本。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/vVXqvwLfSwmx79WSW9QbBQ/zh-cn_image_0000002655847962.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=C6D10231E2F2AEF9CAC55CA67223D705D553DDFF352FA68021B0D0BF54439CA1)


  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/K32X3MGGQQeMKhrTVjuitw/zh-cn_image_0000002656007892.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=ED4B145842D46EC767F9AF47BE9A3D881A7F7CB5D1B056B83F36D2829D653636)

5. 配置Wallet Kit服务参数：服务类型选择票，服务子类型选择门票，服务项目按需选择，并指定服务号、开发者服务公钥及开发者云侧服务地址前缀后，点击“下一步”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/0bE6JaCXTTK3e5g7t_zAHg/zh-cn_image_0000002655847972.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=FAE1AF596DE79E422D7656E818592B33DAABB90DA403547E6EC166BE7E3F6C10)


| 参数 | 说明 |

| --- | --- |

| 服务名称 | Wallet Kit首页列表展示该开发者所有创建的服务时，服务名称用于区分不同的服务。建议命名为公司简称+Wallet Kit+应用场景，长度不超过64个字符。 |

| 服务类型 | 固定选择“票”。 |

| 服务子类型 | 固定选择“门票”。 |

| 服务项目 | 选择接入的服务项目。 |

| 默认卡名称 | 在钱包内显示的默认卡名称 ，长度不超过64个字符。 |

| 服务号 | 开发者服务号，用于区分不同的项目和服务。建议格式为【hwpass.公司简称.项目名称.pass.服务项目】，须以hwpass开头 (自动填充，无需输入)，可为数字、字母，长度不超过32个字符。 |

| 服务公钥 | 开发者将生成的公钥，后续该公钥将作为Wallet Kit服务器认证开发者身份的凭证。 |

| 服务器地址前缀 | 开发者服务器地址，用于Wallet Kit服务器在开卡或删卡成功后回调开发者。如果不需要回调结果，可以不填该字段。 |
6. 配置NFC&二维码参数：可展码通行，但不涉及NFC，默认在用户华为账号登陆的所有设备可见，不支持动态二维码，推荐配置如下。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/f4AjLK7ARLOTpapFmItYkA/zh-cn_image_0000002656007920.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=E761EABCFAF1488D77C6601326013E42B0BE1C3655498E0E8869E07AE94FFE6C)

7. 配置添加预览信息：按要求上传卡面底图。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/cqs-0EgUSnulehZENBs9nw/zh-cn_image_0000002655848000.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=3461AAE59451B30EAD95050F6FAA977BCE34994C4DD1938954BA72E522D84852)

8. 配置卡详情页信息：按需配置卡面个性化信息，功能区，运营区以及官方App/元服务跳转。

  基本信息配置：可指定背景色、字体颜色、LOGO等，并输入样例信息查看实际活动/景点门票的效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/gkmWBcI-R6uVNr6CDbz3bw/zh-cn_image_0000002686087429.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=5686BFC66531C0522325FC273617238259F285AABB3530FB544D136E8D868C83)


  主要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/iXafD1TzS1KyujkwPO5OHg/zh-cn_image_0000002656007916.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=5B9EE74CA5C8EC9605EC2DF130FAB508A31B6C7794E05B8CDA9CFC9351673946)


  次要信息配置：支持自定义标签及内容，最多支持4个栏位。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/iCrvbkC0TI-DZpifi4LwbQ/zh-cn_image_0000002655847996.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=CBAD35433CCD7B4111E6D0198990EB545BFBD8C8E88D49107B05796D2F5CB282)


  功能区配置：支持卡片信息和删除功能。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/8EPvKObYQzWkYWav-ulZ5A/zh-cn_image_0000002685927597.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=B541F237D55592F81CF1B6507821B9BAB5279B55826AA9D6003FA7673EDCA6EE)


| 参数 | 说明 |

| --- | --- |

| 卡片信息 | 用于展示卡面提供服务方（按需配置多语言）信息，按需勾选卡号和联系客服（客服电话方便用户联系）。在详情页点击卡面信息会跳转卡面信息展示。右边可以看到预览效果。 |

| 删除 | 用于控制钱包内删卡。 |

  运营区配置：可以按需配置服务菜单（最多支持5个），按需配置是否提供使用记录查看链接以及华为服务号入口，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/AUJHoFhFTcis532rhJFWhQ/zh-cn_image_0000002656007918.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=FF1C5C41C8BBCD1B055DDF728B094E5ACDDC46C371A1503780AA3448B8393F9B)


| 参数 | 说明 |

| --- | --- |

| 服务菜单 | 用于控制详情页的运营区。如果需要配置，点添加按钮后需要配置菜单名称（多语言可选）以及跳转地址。 |

| 是否提供使用记录查看链接 | 用于控制详情页的运营区是否展示使用记录。 |

| 是否提供华为服务号入口 | 控制详情页的运营区的服务号是否展示，如果需要配置，则填写开通服务号的ID和名称。 |

  官方App/元服务跳转配置：按需配置官方App/元服务跳转，如果选择是，需要按需配置跳转链接，右边可以查看配置的预览效果。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/31kloOp-TQ23g7wGgsMNQg/zh-cn_image_0000002655847998.png?HW-CC-KV=V1&HW-CC-Date=20260730T072211Z&HW-CC-Expire=86400&HW-CC-Sign=1B5AD36E0D49CDB6A000ACEEC3A0D97AAC893BB3458ACE729B7A2234A4FE59EE)

9. 提交前进行信息核对及预览，确认无误后，点击“提交”完成活动/景点门票Wallet Kit服务接入配置。
