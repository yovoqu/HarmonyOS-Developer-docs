# 工具概述

更新时间：2026-07-21 01:13:31

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-deveco-cli-overview

DevEco CLI是一款面向各类AI Agent使用的AI产品，将HarmonyOS工具集、HarmonyOS知识库和精品 Skills 封装为适配AI调用的标准化接口，既可供给DevEco Code集成，也可全面开放给各类通用AI开发工具集成使用，帮助开发者快速开发HarmonyOS应用。
