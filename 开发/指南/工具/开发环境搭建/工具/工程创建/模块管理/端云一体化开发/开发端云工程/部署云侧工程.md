# 部署云侧工程

更新时间：2026-06-12 06:54:33

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/agc-harmonyos-clouddev-deploy

您也可选择在云函数和云数据库全部开发完成后，将整个云工程资源统一部署到AGC云端。
 1. 右击云开发工程（“CloudProgram”），选择“Deploy Cloud Program”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/8E0prtbDQs6mtMlIE2sQCg/zh-cn_image_0000002214858797.png?HW-CC-KV=V1&HW-CC-Date=20260624T020702Z&HW-CC-Expire=86400&HW-CC-Sign=72BFFECC352797A8244C7F4D1048C235C9998752B5A9212A4A09CC1A13A8AEAC)

2. 您可在底部状态栏右侧查看云工程打包与部署进度。请您耐心等待，直至出现“Deploy successfully”消息，表示云工程已成功部署。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/8Igbkvz_T8CD37BHclsYKw/zh-cn_image_0000002179338472.png?HW-CC-KV=V1&HW-CC-Date=20260624T020702Z&HW-CC-Expire=86400&HW-CC-Sign=6F4D70F761B0E1DFF8328092D1FAA08615E792C5FAE633A75F39414893BD9CBC)

3. 在菜单栏选择“Tools > CloudDev”。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/4kxiUWtJSX-PiCKhpjBwPQ/zh-cn_image_0000002214858789.png?HW-CC-KV=V1&HW-CC-Date=20260624T020702Z&HW-CC-Expire=86400&HW-CC-Sign=5BC2E37D17D99A2F8A28654310C0D19CC57AAEC6C75601CC8706A888E4615B30)

4. 在打开的CloudDev面板中，点击“Go to console”，打开当前项目的AGC云开发子控制台。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/8D5VLt40SzmS8fBUquspjA/zh-cn_image_0000002179498156.png?HW-CC-KV=V1&HW-CC-Date=20260624T020702Z&HW-CC-Expire=86400&HW-CC-Sign=C99B1F8A06D55807BD25F5D38F097890ADD565559EA3F3A99DC7C64718CF9F83)

5. 分别进入云函数与云数据库服务菜单，可查看到您刚刚部署的云函数与云数据库资源。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/oA_DaAbjT_ukxWmf9HmlnA/zh-cn_image_0000002467759440.png?HW-CC-KV=V1&HW-CC-Date=20260624T020702Z&HW-CC-Expire=86400&HW-CC-Sign=719582448C20B54C40D388A097724D342070A500F170E13D7BB374A388BBD603)
