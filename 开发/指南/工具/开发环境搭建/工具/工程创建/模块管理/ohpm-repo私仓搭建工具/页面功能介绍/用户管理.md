# 用户管理

更新时间：2026-07-28 12:07:32

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-ohpm-user-management

用户管理页面可以新增用户、修改用户类型、重置用户密码，删除用户和搜索用户，页面效果如下图所示：
 

![](assets/用户管理/file-20260514134328469-0.png)

 

 1. 点击“新增”按钮，弹出新增用户面板，输入新增用户的用户名和密码，新增用户首次登录将强制重置密码。填完用户信息后点击新增即可添加一个新用户，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/y40HiAaTRVmae6BC2QHJ9Q/zh-cn_image_0000002678154223.png?HW-CC-KV=V1&HW-CC-Date=20260730T071812Z&HW-CC-Expire=86400&HW-CC-Sign=95B9B192F0C626FC95597CAAC01D70BE2713D61C32047BC4215F059064B660FC)

2. 点击“编辑类型”按钮，弹出编辑用户类型面板，在此面板中可以修改用户类型成管理员或用户。点击确认修改用户类型，将出现密码输入框，由于管理员修改其他用户的类型是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/ATJYEPDQR2qYc8NeRsm3fg/zh-cn_image_0000002678154219.png?HW-CC-KV=V1&HW-CC-Date=20260730T071812Z&HW-CC-Expire=86400&HW-CC-Sign=6EC7ED6C2B4CFD5AD3BA9B82579AF2DC8E25CFA4C8EE8381A1416D9C0C567598)

3. 点击“重置密码”按钮，弹出重置用户密码面板，在此面板中可以通过点击生成新密码为用户生成随机新密码，并可通过点击复制图标将新密码复制进剪贴板（只有点击**确定**按钮才会重置密码）。点击确认重置密码，将出现密码输入框，由于管理员对其他用户重置密码是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/g2wM9470Te6flpVHpb5XnQ/zh-cn_image_0000002677994307.png?HW-CC-KV=V1&HW-CC-Date=20260730T071812Z&HW-CC-Expire=86400&HW-CC-Sign=487847D9E40E1D77F66D4C0F903D0896CFDF1749CF7B63042DE45176454ADF5B)

4. 点击“删除”按钮，弹出删除提示，如果确定删除，需要点击按钮“是”，将出现密码输入框，由于管理员删除用户属于敏感操作，需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/0-etZeGzS-ODNmCKrlz17A/zh-cn_image_0000002677994191.png?HW-CC-KV=V1&HW-CC-Date=20260730T071812Z&HW-CC-Expire=86400&HW-CC-Sign=16C5D99ED3FAFC44CC0CB20BA34AB441B49701048F205971B29B634CA62A16E2)


  当被删除的用户是某个三方包的唯一所有者时，禁止被删除。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/otzaaMk3R6KBHpmEpgFf7g/zh-cn_image_0000002677994377.png?HW-CC-KV=V1&HW-CC-Date=20260730T071812Z&HW-CC-Expire=86400&HW-CC-Sign=2729C1F1E5303312D039C7933521950EE68E466B99D1D66BB7665A8B59BCE146)

5. 点击搜索框，支持指定用户类型（系统管理员/普通用户）和用户名模糊搜索，搜索页面效果如下图所示（以指定用户类型为系统管理员，用户名为admin为例）：
