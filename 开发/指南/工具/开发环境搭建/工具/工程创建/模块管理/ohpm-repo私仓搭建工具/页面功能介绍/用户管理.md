# 用户管理

更新时间：2026-06-12 06:54:33

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-ohpm-user-management

用户管理页面可以新增用户、修改用户类型、重置用户密码，删除用户和搜索用户，页面效果如下图所示：
 

![](assets/用户管理/file-20260514134328469-0.png)

 

 1. 点击“新增”按钮，弹出新增用户面板，输入新增用户的用户名和密码，新增用户首次登录将强制重置密码。填完用户信息后点击新增即可添加一个新用户，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/vc7dgLrHQROiOQqcLS20CA/zh-cn_image_0000002594632002.png?HW-CC-KV=V1&HW-CC-Date=20260624T020659Z&HW-CC-Expire=86400&HW-CC-Sign=8FF6829114851A7A258268CEF00DE2306896AC621A4D3061A47E26C27631AA52)

2. 点击“编辑类型”按钮，弹出编辑用户类型面板，在此面板中可以修改用户类型成管理员或用户。点击确认修改用户类型，将出现密码输入框，由于管理员修改其他用户的类型是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/-SPyFLcURmy_yEkBTaZtVg/zh-cn_image_0000002625071585.png?HW-CC-KV=V1&HW-CC-Date=20260624T020659Z&HW-CC-Expire=86400&HW-CC-Sign=5DA90F55409FEBDD941C6CCEAB9072ECABD7764CE3AD73C0DBBA2E181D6C94E9)

3. 点击“重置密码”按钮，弹出重置用户密码面板，在此面板中可以通过点击生成新密码为用户生成随机新密码，并可通过点击复制图标将新密码复制进剪贴板（只有点击**确定**按钮才会重置密码）。点击确认重置密码，将出现密码输入框，由于管理员对其他用户重置密码是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/PLwBXKkDRkegDkoY3PGGaw/zh-cn_image_0000002594632010.png?HW-CC-KV=V1&HW-CC-Date=20260624T020659Z&HW-CC-Expire=86400&HW-CC-Sign=30E69E9B34F7A83419FB66CDD0083A78A5174E30940AA68A28369DF116AA5B57)

4. 点击“删除”按钮，弹出删除提示，如果确定删除，需要点击按钮“是”，将出现密码输入框，由于管理员删除用户属于敏感操作，需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/Z6tsh8OTTR-_A1NxfP6dxg/zh-cn_image_0000002625071587.png?HW-CC-KV=V1&HW-CC-Date=20260624T020659Z&HW-CC-Expire=86400&HW-CC-Sign=4A29FB804DAAC3FC12290CD55620DB0702CA24436B5ACAE374F754D30D9B9995)


  当被删除的用户是某个三方包的唯一所有者时，禁止被删除。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/BjeYsaVhR8elaESNQGpbXA/zh-cn_image_0000002594632006.png?HW-CC-KV=V1&HW-CC-Date=20260624T020659Z&HW-CC-Expire=86400&HW-CC-Sign=4A622F3FA9FBA605D1355878F5CBEFE39C66337A4CF5CE1FDC2A42C353F737AD)


5. 点击搜索框，支持指定用户类型（系统管理员/普通用户）和用户名模糊搜索，搜索页面效果如下图所示（以指定用户类型为系统管理员，用户名为admin为例）：
