# 用户管理

更新时间：2026-06-10 12:49:31

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-ohpm-user-management

用户管理页面可以新增用户、修改用户类型、重置用户密码，删除用户和搜索用户，页面效果如下图所示：
 

![](assets/用户管理/file-20260514134328469-0.png)

 

 1. 点击“新增”按钮，弹出新增用户面板，输入新增用户的用户名和密码，新增用户首次登录将强制重置密码。填完用户信息后点击新增即可添加一个新用户，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/Vu10aQgJRN2NT23OeGWzow/zh-cn_image_0000002602184963.png?HW-CC-KV=V1&HW-CC-Date=20260611T074907Z&HW-CC-Expire=86400&HW-CC-Sign=8B90C04CB3ABBD2E68D11C4E0B24FF573759D0AE6A20B8F7B3F03F95E1DBB4DD)

2. 点击“编辑类型”按钮，弹出编辑用户类型面板，在此面板中可以修改用户类型成管理员或用户。点击确认修改用户类型，将出现密码输入框，由于管理员修改其他用户的类型是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/nh3VGx8OQmKAGXImX3dliA/zh-cn_image_0000002571385796.png?HW-CC-KV=V1&HW-CC-Date=20260611T074907Z&HW-CC-Expire=86400&HW-CC-Sign=F50C92F2BC7096DF1731158F9273E64230B3B9FD9ECAAC89842FCC3A51E3C9F7)

3. 点击“重置密码”按钮，弹出重置用户密码面板，在此面板中可以通过点击生成新密码为用户生成随机新密码，并可通过点击复制图标将新密码复制进剪贴板（只有点击**确定**按钮才会重置密码）。点击确认重置密码，将出现密码输入框，由于管理员对其他用户重置密码是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/_sadh8yUT9G0GdhK-fCS1A/zh-cn_image_0000002571545440.png?HW-CC-KV=V1&HW-CC-Date=20260611T074907Z&HW-CC-Expire=86400&HW-CC-Sign=51FE52263B331DB12005AD029764BC3DB8B1283C785684C2C1B099572AA04338)

4. 点击“删除”按钮，弹出删除提示，如果确定删除，需要点击按钮“是”，将出现密码输入框，由于管理员删除用户属于敏感操作，需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/f0Rr3yl2TyiBWhsKIWpikg/zh-cn_image_0000002571545436.png?HW-CC-KV=V1&HW-CC-Date=20260611T074907Z&HW-CC-Expire=86400&HW-CC-Sign=41CAA1F6CE2C875CCB174F0A3334BA27FE30FF83B08F2B4E9FAEAADDA139912F)


  当被删除的用户是某个三方包的唯一所有者时，禁止被删除。

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/2RYiW2bMTX-XCwNmQWP2wQ/zh-cn_image_0000002571385798.png?HW-CC-KV=V1&HW-CC-Date=20260611T074907Z&HW-CC-Expire=86400&HW-CC-Sign=14F91098763EBF474F1137FB184CE88A2D3DC3E31D7FCAF1E14FE473FED34544)


5. 点击搜索框，支持指定用户类型（系统管理员/普通用户）和用户名模糊搜索，搜索页面效果如下图所示（以指定用户类型为系统管理员，用户名为admin为例）：
