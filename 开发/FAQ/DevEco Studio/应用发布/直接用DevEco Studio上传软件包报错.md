# 直接用DevEco Studio上传软件包报错

更新时间：2026-06-26 07:47:42

## 直接用DevEco Studio上传软件包报错
 


##### 问题现象

直接用DevEco Studio上传软件包（Upload product）时报错：The build configuration of the current Build Mode cannot be uploaded，如图
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/aulB16y9SryfYT3jHvkGrg/zh-cn_image_0000002658808915.png?HW-CC-KV=V1&HW-CC-Date=20260701T025924Z&HW-CC-Expire=86400&HW-CC-Sign=B4EDFEA8BA3624A870C617E2B44297C2598B4556891EFB694BA72B6F9C20508D)

 
 

##### 解决方案

使用DevEco Studio上传软件包（Upload Product）时，需要确保Build Mode是release。操作步骤如下：
 
- 点击DevEco Studio上方菜单栏“Select Product”按钮。
- Build Mode切换为release。
