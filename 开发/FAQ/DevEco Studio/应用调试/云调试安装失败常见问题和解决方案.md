## 云调试安装失败常见问题和解决方案
 


##### 问题现象

- **问题一：**开发者在使用云调试安装APP失败，报“BusinessError 17700101: Bundle manager service is excepted.”，如下图：
 
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/eqbh6UW1QxianBN1kUEFDg/zh-cn_image_0000002658808799.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=0A6662FBE1299825FB1D1F564FBFCA1BB1D254D5505A064D59F280E69AC3E3AD)

- **问题二：**应用安装报“应用不匹配当前系统版本，请选择其他系统版本设备”。
 
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/t-XscoG7S6qQDnNm2SGEPA/zh-cn_image_0000002628409534.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=BA37665C504084E2A8CAD24797FFB4E104C4A48FC2E1E5CCE5B774C69E705FD7)

- **问题三：**应用包上传报“请您上传hap/app格式的文件！”。
 
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/euvQzZtwTB2GYDDs8VMJSg/zh-cn_image_0000002628569434.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=C699A43F261405AD770BE5C7ECE0871EA6F56E4C6DD43A848199E9B674B1793F)

- **问题四：**云调试安装release包提示安装失败，报“error: failed to install bundle. code:9568297 error: install failed due to older sdk version in the device”。
- **问题五：**云调试上传软件包耗时过长，浪费免费体验时长。
- **问题六：**云调试安装应用提示：该应用类型不适用于所选设备。应用是2in1，选择的调试真机为matebook pro，但还是报应用类型错误。

 
 

##### 解决方案

- **问题一解决方案：**可以从以下方面进行排查：
 
检查文件完整性，如果是在线文件请确认是否下载完成。
- 检查文件名是否带有特殊符号（如“~”等字符）导致解压失败，需修改相关文件名。如果以上方法还不能解决您的问题，可以继续参考官网[17700101 包管理服务异常](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-bundle#section17700101-包管理服务异常)排查解决。

 - **问题二解决方案：**此类问题是因为机型的系统和应用不兼容，以该问题为例：
 
查看工程目录build-profile.json5文件的compatibleSdkVersion字段，标识应用/元服务运行所需兼容的最低SDK版本为4.0.0（10）。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/FqQdETTJTpinObK79g5zKg/zh-cn_image_0000002658928751.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=8A8B938A6E3891AA796EB0D0AF555F808676F54E9ED0902734FD3B1BEE249F60)

- 开发者在云调试选择的机型API为9，因此该机型的系统和应用不兼容。选择API为10或者10以上的机型即可。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/1xl83ujSSWO-0-iUQtahiA/zh-cn_image_0000002658808803.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=1A27E769AC620D3CBB296FB1F83D7B09268697659BAD11CDD975E60531FB3B3D)


 - **问题三解决方案：**HarmonyOS NEXT的设备只能上传HAP和APP包。
 
如果要上传apk，机型选择页面，筛选条件-系统版本选择以下三个类型。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/3Wnw7gsQQveNQisOuNGB_Q/zh-cn_image_0000002628409536.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=5067FBB0A91FC8F5126FB6CAF57F3EB8BDBE673DB94799B10614FCF73B05618A)

- 选择设备进入，应用上传入口显示支持apk。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/K2LmVa0PTxuHjvQOviziqw/zh-cn_image_0000002628569436.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=5819DA4C6F9E8C6D3ACBC152F5EF6D14331B1E2A65B963F451E04A071A6EA7E1)


 - **问题四解决方案：**该问题原因是云调试设备SDK版本较低，可以通过筛选云调试设备的系统版本来获取相匹配的设备。在云调试平台选择筛选条件，选择与安装包匹配的设备调试：
 
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/tGtoti6JRZK1FeaOhxaXbQ/zh-cn_image_0000002658928753.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=1C45CBE18646E68D408C9B8C74BFDCD8E2F52667D1F27BE2A9658C4DBBEBC341)

- **问题五解决方案：**
在云调试-我的信息-应用中，提前上传需要调试的应用。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/l4qIIw6UQsenH2SLkXoIvg/zh-cn_image_0000002658808805.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=A183E40AE952C2FF551BE828FBA89AFA95F26BB15D8D3A197E9A266E86294AF0)

- 选择调试设备，应用中显示已上传的应用，点击安装即可。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/XrHKxRfgQqKhi7TeoT7AbQ/zh-cn_image_0000002628409540.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=AE645A061AAF31B55B6EF0CCB82E8253EDE2BD99083B64D48C4C5155EF0A3FAA)


 - **问题六解决方案：**“该应用类型不适用于所选设备”这个报错除了是应用类型错误，也可能是因为应用的版本过高，导致云调试的真机设备不能安装。查看工程目录build-profile.json5文件的compatibleSdkVersion字段，修改该字段版本让其小于或等于云调试真机版本。
 
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/aqeC6NEoQuCO4xfXyKzgSA/zh-cn_image_0000002628569438.png?HW-CC-KV=V1&HW-CC-Date=20260701T025920Z&HW-CC-Expire=86400&HW-CC-Sign=217414D7EAFB950A1AE7C1918D433CD04997EC75EF13AD937902B1AF7E94EFF2)
