# 如何解决场景化性能测试脚本运行报错：'NoneType' object has no attribute 'replace'

更新时间：2026-06-30 12:21:30

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-scenario-based-performance-test-16

#### 问题现象

在[场景化性能测试](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/performance-testing#section8642101711299)脚本中右键“执行hypium用例”，出现测试资源加载异常[01100]：'NoneType' object has no attribute 'replace'报错。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/ZJRxbUN5TCy1qClcbcQCcg/zh-cn_image_0000002631135614.png?HW-CC-KV=V1&HW-CC-Date=20260701T041023Z&HW-CC-Expire=86400&HW-CC-Sign=FF9EE1E295E930916937D4F1F98DF620971FBB5F71C80D7B8CB05A2A56BEBC4F)

 
 

#### 解决方案

点击工程中的main.py脚本，右键执行Run 'main'进行调试。
