# 视频通话时，画面比例显示异常

更新时间：2026-06-26 07:48:29

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-camera-24

#### 问题现象

视频通话时，画面比例显示异常，画面明显被拉长了。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/0QiPAnVzQaCnKaUs3FtPIA/zh-cn_image_0000002658911779.png?HW-CC-KV=V1&HW-CC-Date=20260730T072609Z&HW-CC-Expire=86400&HW-CC-Sign=EBD3194E1883BD8E0B7BF337B319AAFD30B70EAEBF2BAE473B0180C233D0DEF3)

 
 

#### 背景知识

- [申请相机开发的权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/camera-preparation)：在开发相机应用时，需要先申请相机相关权限，确保应用拥有访问相机硬件及其他功能的权限。
- [XComponent](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-xcomponent)：提供用于图形绘制和媒体数据写入的Surface，XComponent负责将其嵌入到视图中，支持应用自定义Surface位置和大小。其可通过指定type字段来实现不同的渲染方式，分别为XComponentType.SURFACE和XComponentType.TEXTURE。
- [XComponentType](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-appendix-enums#xcomponenttype10)：枚举值，用于指定XComponent组件类型（渲染方式）。
- [CameraManager](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-camera-cameramanager)：相机输出能力。

 
 

#### 问题定位

- 排查视频预览流分辨率（previewProfiles）与XComponent容器的宽高比是否一致。根据关键词CreatePreviewOutputInstance查找日志，确认采用的previewProfiles的宽高是480*480，宽高比是1:1，日志如下：

  
```bash
C02B01/应用包名/CAMERA                  应用包名  I     {CreatePreviewOutputInstance():869} CameraManagerNapi::CreatePreviewOutputInstance ParseProfile size.width = 480, size.height = 480, format = 1003, surfaceId = 6811818131538
```
 检查XComponent组件的宽高，是100vp*300vp，宽高比是1:3，与视频预览流分辨率的宽高比不一致：

#### 分析结论

- 视频预览分辨率（previewProfiles）与XComponent容器的宽高比不一致，从而导致画面比例显示异常。
- 应用没有根据设备的宽高设置合适的预览流分辨率，而是强制设置自定义值，导致画面比例显示异常。

 
 

#### 修改建议

保持预览分辨率与XComponent容器比例一致。
 
- 方案一：根据使用相机Profile的调整XComponent组件的宽高。
