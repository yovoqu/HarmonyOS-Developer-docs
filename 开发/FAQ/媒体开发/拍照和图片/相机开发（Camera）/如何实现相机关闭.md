# 如何实现相机关闭

更新时间：2026-06-26 07:48:29

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-camera-9

实现相机关闭的参考代码如下：
 
```text
<em>// Stop the current session</em>
  photoSession.stop();

<em>// Release camera input stream</em>
  cameraInput.close();

<em>// Release preview output stream</em>
  previewOutput.release();

<em>// Release the photo output stream</em>
  photoOutput.release();

<em>// Release session</em>
  photoSession.release();

<em>// Session left blank</em>
  photoSession = undefined;
```
