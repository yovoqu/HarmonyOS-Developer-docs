## 基于动态时间补偿实现自定义定时器
 


##### 问题现象

HarmonyOS中Timer(定时器)，并不是按照设定时间严格执行，每次都会有很小误差，在累计起来可能会有几秒的误差，如何规避。
 
 

##### 背景知识

[setTimeout](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-timer#settimeout)：设置一个定时器，该定时器在定时器到期后执行一个函数。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/f3OaIj3XQSq9TanXNYxGcA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T025521Z&HW-CC-Expire=86400&HW-CC-Sign=68270A4CB5FC74B08AB24E1E1B4CDA9626940221E28B9F60BE193072C2582323)
 

- 该计时器非精准计时器，实际延迟可能会与预期延迟存在误差。
- 如果值小于1，会被默认取0。
- delay值受系统限制，超出2^32-1时会溢出，delay值为0。

 

 
 

##### 解决方案

- 时间补偿算法：通过start+time*count-current动态计算下次执行延迟。
```text
async function myInterval(callback: () => void, time: number) {
  let start: number = Date.now();
  let count: number = 1;
  let current: number = start;
  while (true) {
    await sleep(start + time * count - current);
    current = Date.now();
    count++;
    callback();
  }
}
```

- 异步控制流：利用sleep()的Promise机制实现非阻塞等待。
```text
async function sleep(time: number) {
  return await new Promise(resolve => setTimeout(resolve, time));
}
```

- 误差控制：每次回调后更新当前时间戳，重置计时基准。完整代码如下：
```text
async function sleep(time: number) {
  return await new Promise(resolve => setTimeout(resolve, time));
}

async function myInterval(callback: () => void, time: number) {
  let start: number = Date.now();
  let count: number = 1;
  let current: number = start;
  while (true) {
    await sleep(start + time * count - current);
    current = Date.now();
    count++;
    callback();
  }
}

          let count: number = 1;

          }, 1000);
        });
    }

  }
}
```
