# 如何解决文件的中文乱码问题

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-local-file-manager-4

读取文件内容的buffer数据后，通过TextDecoder对文件内容进行解码。
 
```text
import { util } from '@kit.ArkTS';
import { fileIo } from '@kit.CoreFileKit';

<em>// In the utility class, retrieve the Context from the Entry Ability and save it to AppStore, then use AppStore to retrieve it in the utility class</em>
let context = AppStorage.get("context") as UIContext;
<em>// Create a file to write Chinese characters</em>
let filePath = context.getHostContext()!.filesDir + "/test0.txt";
let file = fileIo.openSync(filePath, fileIo.OpenMode.READ_WRITE | fileIo.OpenMode.CREATE);
<em>// Write a paragraph of content to a file</em>
let writeLen = fileIo.writeSync(file.fd, "Hello, world");
fileIo.closeSync(file);
console.info(`GarbledCnCharacters The length of str is: ${writeLen}`);
let stream = fileIo.createStreamSync(filePath, "r+");
let buffer = new ArrayBuffer(4096);
stream.readSync(buffer);
<em>// Set the encoding format to "utf-8"</em>
let textDecoder = util.TextDecoder.create('utf-8', { ignoreBOM: true });
<em>// Retrieve the corresponding text after decoding the input</em>
let readString = textDecoder.decodeToString(new Uint8Array(buffer), { stream: false });
console.info(`GarbledCnCharacters read content is:${readString}`);
```
