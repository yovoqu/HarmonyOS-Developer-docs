# 后台位置上报类型长时任务开发指导

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-background-tasks-13

#### 问题现象

员工外出工作，需要每隔一定时间上报一次位置，应用处于后台运行的案例。
 
 

#### 背景知识

- [长时任务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/continuous-task)：应用退至后台后，在后台需要长时间运行用户可感知的任务，如导航等。为防止应用进程被挂起，导致对应功能异常，可以申请长时任务，使应用在后台长时间运行。
- [Location Kit（位置服务）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/location-kit-intro#section884410581151)：位置子系统使用多种定位技术提供服务，通过这些定位技术，无论用户设备在室内或是户外，都可以准确地确定设备位置。通过[on('locationChange')](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-geolocationmanager#geolocationmanageronlocationchange)开启位置变化监听，可实时获取当前位置信息。

 
 

#### 解决方案
1. 申请ohos.permission.KEEP_BACKGROUND_RUNNING、ohos.permission.LOCATION、ohos.permission.APPROXIMATELY_LOCATION权限，配置方式请参见[声明权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/declare-permissions)。
2. 声明后台模式类型：在[module.json5配置文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/module-configuration-file)中abilities下的backgroundModes字段里，为需要使用长时任务的UIAbility声明相应的长时任务类型，配置文件中填写长时任务类型的[配置项](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/continuous-task#使用场景)。

  
```json
"backgroundModes": [
  "location"
],
```

3. 定位能力先申请定位权限，然后在定位功能启动时可同步启动后台定位长时任务，在取消定位时同时取消长时任务，完整代码如下：
```json
import { geoLocationManager } from '@kit.LocationKit';
import { abilityAccessCtrl, common, PermissionRequestResult, Permissions, WantAgent, wantAgent } from '@kit.AbilityKit';
import { backgroundTaskManager } from '@kit.BackgroundTasksKit';

@Entry
@Component
struct Index {
  private context: common.UIAbilityContext = this.getUIContext().getHostContext() as common.UIAbilityContext;
  @State workingState: boolean = false;
  @State locationInfos: Array<LocationInfo> = [];

  aboutToAppear() {
   <em> // 申请定位权限</em>
    let permissions: Array<Permissions> = ['ohos.permission.LOCATION', 'ohos.permission.APPROXIMATELY_LOCATION'];
    this.reqPermissionsFromUser(permissions);
  }

  reqPermissionsFromUser(permissions: Array<Permissions>): void {
    let atManager: abilityAccessCtrl.AtManager = abilityAccessCtrl.createAtManager();
   <em> // requestPermissionsFromUser会判断权限的授权状态来决定是否唤起弹窗</em>
    atManager.requestPermissionsFromUser(this.context, permissions).then((data: PermissionRequestResult) => {
      console.info(`requestPermissionsFromUser success, result: ${JSON.stringify(data)}`);
    }).catch((err: BusinessError) => {
      console.error(`Failed to request permissions from user. Code is ${err.code}, message is ${err.message}`);
    });
  }

  build() {
    Column({ space: 16 }) {
      Row() {
        Column({ space: 20 }) {
          Row({ space: 15 }) {
            Image($r('sys.media.person_shield'))
              .width(30)
              .height(30)

            Text('张三')
          }

          Text('外出场所：大运广场')
        }
        .alignItems(HorizontalAlign.Start)
        .width('70%')

        Blank().width(2).backgroundColor(Color.Gray)

        Column() {
          Column() {
            if (this.workingState) {
              Text('结束')
            } else {
              Text('开始')
            }
            Text('工作')
          }
          .padding(5)
          .backgroundColor(this.workingState ? '#E84026' : '#64BB5C')
          .borderRadius($r('sys.float.corner_radius_level4'))
          .onClick(() => {
            if (this.workingState) {
              this.offLocationListen();
              this.stopContinuousTask();
            } else {
              this.getLocation();
              this.startContinuousTask();
            }
          });
        }
        .width('29%')
      }
      .width('100%')
      .padding(14)
      .borderRadius(8)
      .backgroundColor(Color.White)

      Column() {
        Row() {
          Text('位置信息列表')

          Text(`Total: ${this.locationInfos.length}`)
        }
        .width('100%')
        .justifyContent(FlexAlign.SpaceBetween)

        Scroll() {
          List({ space: 5 }) {
            ForEach(this.locationInfos, (item: LocationInfo) => {
              ListItem() {
                Column() {
                  Text(`时间：${item.time}`)

                  Text(`坐标：[${item.latitude}, ${item.longitude}]`)

                  Text(`地址：${item.adress}`)
                }
                .width('100%')
                .padding(5)
                .borderRadius(5)
                .alignItems(HorizontalAlign.Start)
                .backgroundColor('#0C0A59F7')
              }
            })
          }
        }
        .scrollBar(BarState.Off)
        .padding({ top: 5, bottom: 10 })
      }
      .width('100%')
      .height('100%')
      .padding(14)
      .borderRadius(8)
      .flexShrink(999)
      .backgroundColor(Color.White)
    }
    .height('100%')
    .width('100%')
    .padding(12)
    .backgroundColor('#f1f3f5')
  }

  locationChange = async (location: geoLocationManager.Location) => {
    if (location) {
      this.workingState = true;
      if (this.locationInfos.length >= 50) {
        this.locationInfos.pop();
      }

      let info = new LocationInfo();
      info.location = location;
      info.latitude = location?.latitude.toFixed(5);
      info.longitude = location?.longitude.toFixed(5);
      info.time = new Date(location?.timeStamp).toLocaleString('zh-CN', { hour12: false });
      let address = await this.getAddressFromLocation(location.latitude, location.longitude);
      info.adress = address;
      this.locationInfos.push(info);
    }
  };

<em>  /**</em>
<em>   * 每隔2秒上报一次位置</em>
<em>   */</em>
  getLocation() {
    let requestInfo: geoLocationManager.LocationRequest = {
      'priority': geoLocationManager.LocationRequestPriority.FIRST_FIX,
      'scenario': geoLocationManager.LocationRequestScenario.UNSET,
      'timeInterval': 2,
      'distanceInterval': 0,
      'maxAccuracy': 0
    };

    try {
      geoLocationManager.on('locationChange', requestInfo, this.locationChange);
    } catch (err) {
      console.error(`getLocation errCode: ${err?.code},errMessage: ${err?.message}`);
    }
  }

  <em>/**</em>
<em>   * 坐标转化为地址</em>
<em>   */</em>
  async getAddressFromLocation(lati: number, long: number): Promise<string> {
    let address: string | undefined = '';
    let reverseGeocodeRequest: geoLocationManager.ReverseGeoCodeRequest = {
      'latitude': lati,
      'longitude': long,
      'maxItems': 1
    };
    let locationResult = await geoLocationManager.getAddressesFromLocation(reverseGeocodeRequest);
    console.log(`locationResult => ${JSON.stringify(locationResult)}`);
    if (locationResult && locationResult.length > 0) {
      address = locationResult[0].placeName;
    }
    return address ? address : '';
  }

 <em> /**</em>
<em>   * 关闭位置上报</em>
<em>   */</em>
  offLocationListen() {
    try {
   <em>   // 需要取消订阅的回调函数。该回调函数需要与on接口传入的回调函数保持一致。若无此参数，则取消当前类型的所有订阅。</em>
      geoLocationManager.off('locationChange', this.locationChange);
      this.workingState = false;
      this.locationInfos = [];
    } catch (err) {
      console.error(`offLocationListen errCode: ${err?.code},errMessage: ${err?.message}`);
    }
  }

  startContinuousTask() {
    let wantAgentInfo: wantAgent.WantAgentInfo = {
   <em>   // 点击通知后，将要执行的动作列表</em>
<em>      // 添加需要被拉起应用的bundleName和abilityName</em>
      wants: [
        {
          bundleName: this.context.abilityInfo.bundleName,
          abilityName: 'EntryAbility'
        }
      ],
   <em>   // 指定点击通知栏消息后的动作是拉起ability</em>
      actionType: wantAgent.OperationType.START_ABILITY,
   <em>   // 使用者自定义的一个私有值</em>
      requestCode: 0,
     <em> // 点击通知后，动作执行属性</em>
      actionFlags: [wantAgent.WantAgentFlags.UPDATE_PRESENT_FLAG]
    };

  <em>  // 通过wantAgent模块下getWantAgent方法获取WantAgent对象</em>
    wantAgent.getWantAgent(wantAgentInfo).then((wantAgentObj: WantAgent) => {
      backgroundTaskManager.startBackgroundRunning(this.context,
        backgroundTaskManager.BackgroundMode.LOCATION, wantAgentObj).then(() => {
        console.info(`Succeeded in operationing startBackgroundRunning.`);
      }).catch((err: BusinessError) => {
        console.error(`Failed to operation startBackgroundRunning. Code is ${err.code}, message is ${err.message}`);
      });
    });
  }

  stopContinuousTask() {
    backgroundTaskManager.stopBackgroundRunning(this.context).then(() => {
      console.info(`Succeeded in operationing stopBackgroundRunning.`);
    }).catch((err: BusinessError) => {
      console.error(`Failed to operation stopBackgroundRunning. Code is ${err.code}, message is ${err.message}`);
    });
  }
}

class LocationInfo {
  public location: geoLocationManager.Location | undefined;
  public latitude: string = '';
  public longitude: string = '';
  public adress: string = '';
  public time: string = '';
}
```

 
 

#### 常见FAQ

Q：应用置于后台一段时间后会被冻结，报FROZEN_BY_DEVICE_STILL_ENTER。
 
A：FROZEN_BY_DEVICE_STILL_ENTER表示应用基于定位的长时任务，在应用退至后台进入静止状态超过3分钟或者应用退后台前已进入静止超过30秒，系统会主动进行冻结。
