# 如何隐藏应用启动时展示的应用图标

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-ability-150

#### 问题现象

应用启动时会先展示应用图标，然后再跳转至首页（如下效果图所示）。如何隐藏该应用图标呢？
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/GUf30hjZQUG3DCf-PmHtTA/zh-cn_image_0000002628789248.png?HW-CC-KV=V1&HW-CC-Date=20260723T012452Z&HW-CC-Expire=86400&HW-CC-Sign=F4055FD19EB11375CB41D7558BC48172F09AEFD108F82737D021D455E5D8DE68)

 
 

#### 背景知识

[abilities标签](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/module-configuration-file#abilities标签)描述UIAbility组件的配置信息，标签值为数组类型，该标签下的配置只对当前UIAbility生效。其中startWindowIcon指定当前UIAbility组件启动页面图标资源文件，startWindowBackground指定当前UIAbility组件启动页面背景颜色资源文件。
 
 

#### 解决方案
1. 将entry模块的module.json5配置文件中abilities标签下的startWindowIcon字段设置为透明的空图片。
```json
"startWindowIcon": "$media:startIcon1",<em> // 将启动页面图标设置成透明的空图片</em>
"startWindowBackground": "$color:start_window_background",<em> // 背景颜色</em>
```

2. 对于浅色模式和深色模式下，可以分别在entry模块的两个color.json配置文件中配置两套color资源，startWindowBackground配置白色和黑色即可。其中浅色模式的color.json文件路径为“src/main/resources/base/element/color.json”；深色模式的color.json文件路径为“src/main/resources/dark/element/color.json”。浅色模式：

  
```json
{
  "color": [
    {
      "name": "start_window_background",
      "value": "#FFFFFF"
    }
  ]
}
```
 效果预览：

  
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/fjUU5YeOQG2WOoZf5FCc7Q/zh-cn_image_0000002628629350.png?HW-CC-KV=V1&HW-CC-Date=20260723T012452Z&HW-CC-Expire=86400&HW-CC-Sign=C2B71680473A6D69F723EF479DD25AB0C6203415B5D94480CDF5650FE2C5159B)


  深色模式：

  
```json
{
  "color": [
    {
      "name": "start_window_background",
      "value": "#000000"
    }
  ]
}
```
 效果预览：
