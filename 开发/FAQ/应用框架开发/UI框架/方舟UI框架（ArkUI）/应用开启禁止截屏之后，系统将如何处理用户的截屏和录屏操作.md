# 应用开启禁止截屏之后，用户进行截屏以及录屏后的行为是什么

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-237

设置窗口为隐私模式后，截屏、录屏、分享屏幕时，系统会阻止这些操作，同时显示灰色蒙层作为视觉提示。
