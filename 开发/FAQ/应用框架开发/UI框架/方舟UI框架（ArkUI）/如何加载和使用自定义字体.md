# 如何加载和使用自定义字体

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-21

1. 字体管理中[@ohos.font (注册自定义字体)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-font)。
> [!NOTE]
> 从DevEco Studio 6.0.0 Beta2版本开始，新建工程或模块时，默认创建的模块不会对非resources目录下的资源进行打包，需使能相关开关：模块的build-profile.json5中buildOption > resOptions > copyCodeResource > enable设置为true，详见resOptions中 copyCodeResource 相关介绍。

2. 设置对应文本的字体家族。可参考以下代码：
```ArkTS
<em>// xxx.ets</em>
import { Font } from '@kit.ArkUI';

@Entry
@Component
struct FontExample {
  @State message: string = 'Hello World';

  aboutToAppear() {
   <em> // Register in black font</em>
    let font: Font = this.getUIContext().getFont()
    font.registerFont({
      familyName: 'Condensed_Black', <em>// Registered font name</em>
      familySrc: '/font/Sans_Condensed_Black.ttf' <em>// The font folder is at the same level as the pages directory</em>
    })

   <em> // Register in black oblique font</em>
    font.registerFont({
      familyName: 'Condensed_Black_Italic', <em>// Registered font name</em>
      familySrc: '/font/Sans_Condensed_Black_Italic.ttf' <em>// The font folder is at the same level as the pages directory</em>
    })
  }

  build() {
    Column() {
      Text(this.message)
        .align(Alignment.Center)
        .fontSize(50)
        .fontFamily('Condensed_Black') <em>// Use black font</em>
      Text(this.message)
        .align(Alignment.Center)
        .fontSize(50)
        .fontFamily('Condensed_Black_Italic') <em>// Use black oblique font</em>
      Text(this.message)
        .align(Alignment.Center)
        .fontSize(50)
    }
    .width('100%')
    .margin({ top: 30 })
  }
}
```
