# 按钮设置渐变属性后如何设置按压效果

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-924

#### 问题现象

按钮设置了linearGradient渐变属性后，长按没有按压态显示效果，该如何设置呢？

#### 背景知识

- 组件可通过设置[linearGradient](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-gradient-color)属性设置组件的颜色渐变效果。
- [hdsEffect](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ui-design-hdseffect)：本模块提供组件的拓展视效能力，包括组件点光源效果、按压光效、动画控制。

 
 

#### 解决方案

- **方案一**：参考[按压阴影](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ui-design-visual-effect-background-color)实现。hdsEffect模块从6.0.0(20)Beta1版本开始，新增支持。
- **方案二**：设置颜色渐变后，长按按钮不会让渐变色变暗。需要识别长按事件[LongPressGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-longpressgesture)，在其中修改linearGradient参数。

#### 总结

只使用backgroundColor修改按钮背景，支持按压态，将背景变灰。但如果使用linearGradient、backgroundImage等属性修改背景，则渐变色、背景图部分不会自动变灰，需要开发者自行实现。
 
修改opacity有类似的效果，对于上述按钮，调低会使按钮变白，不能满足要求。
