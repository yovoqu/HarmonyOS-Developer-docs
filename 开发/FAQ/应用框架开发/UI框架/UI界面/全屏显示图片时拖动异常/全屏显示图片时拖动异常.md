# 全屏显示图片时拖动异常

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1563

#### 问题现象

场景一：全屏显示图片时，未放大图片也可拖动图片。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/d_midsfdRF-7d2u4QP29YQ/zh-cn_image_0000002628609858.png?HW-CC-KV=V1&HW-CC-Date=20260723T012935Z&HW-CC-Expire=86400&HW-CC-Sign=3F9D8736B7BEED0D74BF42B0FDC0183F5CD1D57F4771EC2C3DCA1369C246D74A)

 
场景二：图片全屏显示后拖动图片到其他位置，停止拖动后图片无法回到原来位置，页面布局异常。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/HNTw9UYkTiSXGxXidyLKBQ/zh-cn_image_0000002628769752.png?HW-CC-KV=V1&HW-CC-Date=20260723T012935Z&HW-CC-Expire=86400&HW-CC-Sign=59C5C56AC79BF4A40DB192DB2B90D69DE28F209B5DF7BB06C7E970C0E8C2F797)

 
 

#### 背景知识

- [Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)为图片组件，常用于在应用中显示图片。
- [PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)为滑动手势事件，当滑动的最小距离达到设定的最小值时触发滑动手势事件。
- [PinchGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pinchgesture)用于触发捏合手势，触发捏合手势的最少手指为2指，最大为5指，最小识别距离为5vp。
- [组合手势](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-combined-gestures)即多种手势组合为复合手势，支持连续识别、并行识别和互斥识别。通过[GestureGroup接口](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-combined-gestures#接口)实现。
- [translate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-transformation#translate)可设置组件平移。

 
 

#### 问题定位

场景一：
 1. 使用DevEco Testing查看问题组件，该组件为Image组件。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/XxumiPX2RKCHZnkNxjEU7w/zh-cn_image_0000002658969073.png?HW-CC-KV=V1&HW-CC-Date=20260723T012935Z&HW-CC-Expire=86400&HW-CC-Sign=A0A5BF4F002015D9108857D437BF1DBA01E17DDE7E4E831871AB7B0F2E9B704F)

2. 查看Image组件的设置，该组件绑定了PinchGesture和PanGesture，实现图片放大缩小和图片移动功能，且没有对图片未放大时的交互做限制，未放大时也能移动。正常情况下应用能够放大图片并移动图片查看细节。
```text

  Image($r('app.media.product003')) <em>// $r('app.media.product003')需要替换为开发者需要的图片资源文件</em>
    .width('80%')
    .objectFit(ImageFit.Contain)
    .backgroundColor(Color.White)
    .translate({ x: this.offsetX, y: this.offsetY, z: 0 }) <em>// 移动图片</em>
    .scale({ x: this.scaleValue, y: this.scaleValue, z: 1 }); <em>// 缩放图片</em>
}
.height('100%')
.width('100%')
.gesture(
  GestureGroup(GestureMode.Exclusive,
  <em>  // 双指缩放</em>
    PinchGesture({ fingers: 2 })
      .onActionUpdate((event: GestureEvent) => {
        if (event) {
          this.scaleValue = this.pinchValue * event.scale;
        }
      })
      .onActionEnd(() => {
        this.pinchValue = this.scaleValue;
      })
    ,
    <em>// 拖动图片，且未放大时也能移动</em>
    PanGesture(this.panOption)
      .onActionUpdate((event: GestureEvent) => {
        if (event) {
          this.offsetX = this.lastX + event.offsetX;
          this.offsetY = this.lastY + event.offsetY;
        }
      })

        this.lastX = this.offsetX;
```

场景二：
 1. 使用DevEco Testing查看问题组件，该问题组件为Image组件。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/yMBSADOcSASCK5RDTX3VQg/zh-cn_image_0000002658849121.png?HW-CC-KV=V1&HW-CC-Date=20260723T012935Z&HW-CC-Expire=86400&HW-CC-Sign=1EFA27B107673E6CA833BC3A3C97488DFF386383FA3B87084E7D8A744EC36556)

2. 查看该Image组件的设置，Image组件通过PanGesture响应滑动手势事件，并通过translate实现平移功能。然而组件在onActionEnd中设置了滑动结束后更新图片位置，导致图片后无法回到原来位置。
```text
@Component
export struct Dialog {
  pageInfos: NavPathStack = new NavPathStack();
  @State offsetX: number = 0;
  @State offsetY: number = 0;
  @State positionX: number = 0;
  @State positionY: number = 0;
  private panOption: PanGestureOptions = new PanGestureOptions({ direction: PanDirection.Vertical });

  build() {
    NavDestination() {
      Stack() {
        Column()
        Image($r('app.media.beauty')) <em>// $r('app.media.beauty')需要替换为开发者</em>
          .translate({ x: this.offsetX, y: this.offsetY }) <em>// 平移图片</em>
      }
      .height('100%')
      .width('100%')
      .gesture(
        PanGesture(this.panOption)
          .onActionUpdate((event: GestureEvent) => {
            if (event) {
              this.offsetX = this.positionX + event.offsetX;
              this.offsetY = this.positionY + event.offsetY;
            }
          })
          .onActionEnd((event: GestureEvent) => {
          <em>  // 滑动结束后更新图片位置</em>
            this.positionX = this.offsetX;
            this.positionY = this.offsetY;
          })
      )
    }
  }
}
```

 
 

#### 分析结论

场景一：应用设置了图片能够放大缩小和移动，但没有对图片未放大时的交互做限制，导致全屏显示图片时，未放大的图片也能够响应拖拽手势。
 
场景二：Image组件在onActionEnd中设置了拖动结束后更新图片位置，导致停止拖动图片后无法回到原来位置。
 
 

#### 修改建议

- 场景一：设置图片放大后才能拖动，避免未放大时图片未固定。

  关键代码如下：

  
```text

   <em> // 放大后才可拖动图片</em>
    this.myDragable = true;
  } else {
   <em> // 原来尺寸或缩小时无法拖动图片</em>
    this.myDragable = false;
  }
}
```
 
```text
.gesture(
  GestureGroup(GestureMode.Exclusive,
    <em>// 双指缩放</em>
    PinchGesture({ fingers: 2 })
      .onActionUpdate((event: GestureEvent) => {
        if (event) {
          this.scaleValue = this.pinchValue * event.scale; <em>// 获取缩放比例</em>
        }
      })
      .onActionEnd(() => {
        this.pinchValue = this.scaleValue;
      })
    ,
   <em> // 拖动图片</em>
    PanGesture(this.panOption)
      .onActionUpdate((event: GestureEvent) => {
        <em>// 缩放比例大于1时才可拖动</em>
        if (event && this.myDragable) {
          this.offsetX = this.lastX + event.offsetX;
          this.offsetY = this.lastY + event.offsetY;
        }
      })
```
