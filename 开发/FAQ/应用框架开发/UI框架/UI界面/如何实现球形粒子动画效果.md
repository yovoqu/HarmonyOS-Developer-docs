#### 问题现象

如何实现一个球形粒子动画的效果？

#### 背景知识

粒子动画是一种通过在一定范围内随机生成的大量粒子的运动来组成的动画效果。在HarmonyOS中，这种动画效果主要通过[Particle](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-particle-animation)组件来实现。
 
 

#### 解决方案
1. 通过Stack布局函数构建了一个包含粒子特效的界面。
2. 创建了一个Particle粒子系统，配置了粒子的各种属性，例如粒子的发射率、生命周期、颜色、透明度、缩放、加速度等。
3. 设置了一个扰动场（Disturbance Fields），用于影响粒子的行为。
4. 监听视图区域的变化，并根据新的视图尺寸调整扰动场的大小和位置。
