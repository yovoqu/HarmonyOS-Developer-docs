# 如何实现旋转共享元素转场

更新时间：2026-06-26 09:07:13

#### 问题现象

利用共享元素转场实现页面跳转，跳转前页面是竖向展示，跳转后页面是横向展示，如何实现该场景？

#### 背景知识

- [组件内隐式共享元素转场 (geometryTransition)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-geometrytransition)：在视图切换过程中提供丝滑的上下文传承过渡。
- [rotate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-transformation#rotate)：设置组件旋转。
- [animateTo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-uicontext#animateto)：提供animateTo接口来指定由于闭包代码导致的状态变化插入过渡动效。
