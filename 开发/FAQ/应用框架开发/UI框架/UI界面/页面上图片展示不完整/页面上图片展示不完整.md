# 页面上图片展示不完整

#### 背景知识

- [Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)为图片组件，常用于在应用中显示图片。
- [objectFit](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image#objectfit)：设置图片的缩放类型。
- [background-size](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009)可以通过设置背景尺寸来控制图片的缩放比例，以实现不同的背景填充效果。

 
 

#### 问题定位
1. 使用DevEco Testing查看问题组件，该组件为Image组件。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3f/v3/SJQ7OQA1TGSG38ctvfnjPw/zh-cn_image_0000002628773276.png?HW-CC-KV=V1&HW-CC-Date=20260730T072429Z&HW-CC-Expire=86400&HW-CC-Sign=117801B1F41645719356EF493C0A06917C1082E3A50CED80BAC6B7998E36603C)

2. 查看Image组件的objectFit属性是否正确，图片的缩放模式选用不当可能造成图片显示不完整，如果图片缩放模式设置为cover，图片会保持宽高比，并填满容器，超出部分会被裁剪。
```text
@Entry
@Component
struct ImgEmpty {


  build() {
    Stack() {
      Image($r('app.media.product')) <em>// $r('app.media.product')需要替换为开发者需要的图片资源文件</em>
        .width(300)
        .height(200)
        .objectFit(ImageFit.Cover) <em>// 图片保持宽高比并填满容器，超出部分会被裁剪</em>
    }
    .width('100%')
    .height('100%');
  }
}
```

 
 

#### 分析结论

图片使用了不合适的缩放模式，造成超出容器的部分被裁剪，导致图片显示不完整。
 
 

#### 修改建议

objectFit属性设置为Contain，该缩放模式会保持宽高比，完整显示图片。
 
```text
@Entry
@Component
struct ImgTruncation {
  build() {
    Stack() {
      Image($r('app.media.product')) <em>// $r('app.media.product')需要替换为开发者需要的图片资源文件</em>
        .width(300)
        .height(200)
        .objectFit(ImageFit.Contain) <em>// 保持宽高比，完整显示图片</em>
    }
    .width('100%')
    .height('100%');
  }
}
```
