# 计算文本分页数据

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-517

#### 问题现象

一段长文本，字体大小可修改，根据文本和字体大小计算当前文本分为几页，以及每页上的行数。
 
 

#### 背景知识

- [measureTextSize](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-measureutils#measuretextsize12)：计算指定文本的宽度和高度。
- [getDefaultDisplaySync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-display#displaygetdefaultdisplaysync9)：获取当前默认的display对象。
- [getLineCount](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-graphics-text#getlinecount)用于返回文本的总行数。
