# 在折叠屏展开态下，页面内容重叠

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-803

#### 问题现象

在折叠屏展开态下，页面部分内容出现了重叠。效果图如下：
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/lWl2fWMwQfGwMScF-QTFQQ/zh-cn_image_0000002658917107.png?HW-CC-KV=V1&HW-CC-Date=20260701T041154Z&HW-CC-Expire=86400&HW-CC-Sign=EA7667499BED4F29860291D27DC9118EE1F8E311EC4F0B5543D0E90F5FED2E99)

 
 

#### 背景知识

[尺寸设置](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-size)：可设置组件的宽高、边距。通过设置width、height、padding、margin等尺寸通用属性调整组件尺寸。
 
 

#### 问题定位

使用[DevEco Testing](https://developer.huawei.com/consumer/cn/download/deveco-testing)查看页面布局，发现子组件的高度大于父组件的高度，溢出了父组件的范围。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/j_yrVzs_RPqk408eOElzFQ/zh-cn_image_0000002628397886.png?HW-CC-KV=V1&HW-CC-Date=20260701T041154Z&HW-CC-Expire=86400&HW-CC-Sign=2E74E7602F46DB1484D969634939912E039900CEBC8B021D95CEC55D51475352)

 
 

#### 分析结论

当前页面子组件的高度大于父组件的高度，溢出了父组件的范围，导致在折叠屏展开态下，页面内容重叠。
 
 

#### 修改建议

父组件不设置高度或将高度设置为auto，使父容器的高度自适应子组件的高度。示例代码如下：
 
```text
@Entry
@Component
struct HeightAutoPage {
  message: string = 'Hello World';
  controller: VideoController = new VideoController();

  build() {
    Column() {
      Scroll() {
        Column() {
          Column() {
            Image($r('app.media.startIcon'))<em> // 请替换成实际资源图片</em>
              .width('20%')
              .objectFit(ImageFit.Contain);
            Text(this.message)
              .fontSize(20)
              .fontWeight(600)
              .margin({ top: 16, bottom: 16 });
            Image($r('app.media.startIcon')) <em>// 请替换成实际资源图片</em>
              .width('20%')
              .objectFit(ImageFit.Contain);
            Text(this.message)
              .fontSize(20)
              .fontWeight(600)
              .margin({ top: 16, bottom: 16 });
            Image($r('app.media.startIcon')) <em>// 请替换成实际资源图片</em>
              .width('20%')
              .objectFit(ImageFit.Contain);
            Text(this.message)
              .fontSize(20)
              .fontWeight(600)
              .margin({ top: 16, bottom: 16 });
            Image($r('app.media.startIcon')) <em>// 请替换成实际资源图片</em>
              .width('20%')
              .objectFit(ImageFit.Contain);
          }
          .width('100%')
          .height('auto') <em>// 父组件高度设置为auto，使父容器的高度自适应子组件的高度</em>
          .margin({ top: 16 });

          Text(this.message)
            .fontSize(20)
            .fontWeight(600)
            .margin({ top: 16, bottom: 16 });
          Column()
            .width('100%')
            .height(300)
            .backgroundColor('#f1f3f5');
        }
        .justifyContent(FlexAlign.Start);
      }
      .height('100%')
      .width('100%')
      .scrollBar(BarState.Off);
    }
    .height('100%')
    .width('100%');
  }
}
```
