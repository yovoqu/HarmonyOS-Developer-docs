# 不同机型默认返回的fontWeightScale不同是否正常

更新时间：2026-07-15 01:37:37

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1659

#### 问题现象

适配字体变化时，不同机型默认返回的fontWeightScale不同，部分机型默认为1.0，部分机型默认为1.1，是否正常？
 
 

#### 解决方案

不同机型默认返回的fontWeightScale不同属于正常现象。部分机型的fontWeightScale默认值为1.1，是该设备产品单独定制的配置，并非异常。
