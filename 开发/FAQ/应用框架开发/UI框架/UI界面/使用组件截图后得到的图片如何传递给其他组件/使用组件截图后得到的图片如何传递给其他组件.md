# 使用组件截图后得到的图片如何传递给其他组件

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1410

#### 问题现象

组件截图后如何传递到其他组件进行显示？
 
 

#### 效果预览


![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/LbFoTubXQb-CB-iK--orxg/zh-cn_image_0000002628763166.gif?HW-CC-KV=V1&HW-CC-Date=20260730T072443Z&HW-CC-Expire=86400&HW-CC-Sign=DD59515D8E523D7072FB86FC143F2EDB6DA934F2D5808A4EA6C92B3EFAC7A73E)

 
 

#### 背景知识

Class (ComponentSnapshot)中[get()](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-componentsnapshot#get12-1)方法可以通过组件标识找到对应组件进行截图，并返回[PixelMap](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-image-pixelmap)格式的图片。
 
 

#### 解决方案

以自定义弹窗组件为示例：
 1. 给需要截图的组件Scroll添加组件标识。
2. 调用componentSnapshot.get根据组件标识进行截图。
3. 得到的PixelMap图片传递弹窗组件。

#### 常见FAQ

Q：调用this.getUIContext().getComponentSnapshot().get()接口是否需要申请权限？
 
A：不需要，接口说明中无权限要求。
 
Q：调用this.getUIContext().getComponentSnapshot().get()接口失败，错误码100001，原因是什么？
 
A：错误码100001标识无效的ID，接口参数ID，不支持未挂树组件，当传入的组件标识是离屏或缓存未挂树的节点时，系统不会对其进行截图。确认ID对应的组件是否存在。
