# 实现游戏摇杆控制角色移动的动画效果

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-638

#### 问题现象

在使用ArkTS开发的游戏页面中，希望实现一个游戏摇杆（虚拟摇杆），通过摇杆控制物体的移动。当按下摇杆滑动时，物体应该按照摇杆方向开始移动；当松开摇杆时，角色停止移动，并且摇杆小球恢复原位，此场景应如何实现？

#### 背景知识

- UIContext提供[animateTo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-uicontext#animateto)接口来指定由于闭包代码导致的状态变化插入过渡动效，可在其中设置动画效果相关参数。
- [transition](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-component#transition)用于设置组件插入显示和删除隐藏的过渡效果。

 
 

#### 解决方案
1. 定义虚拟摇杆。
由两个Circle组成，设置大小圆半径以及摇杆中心区域小球位置以及初始位置。
```text
Row() {
  Circle({ width: this.maxRadius * 2, height: this.maxRadius * 2 })
    .fill('#20101010')
    .position({ x: this.centerX - this.maxRadius, y: this.centerY - this.maxRadius })
  Circle({ width: this.radius * 2, height: this.radius * 2 })
    .fill('#403A3A3A')
    .position({ x: this.positionX - this.radius, y: this.positionY - this.radius })
}
.height(240)
.width(240)
.justifyContent(FlexAlign.Center)
.position({ x: 0, y: 120 })
.onTouch(this.handleTouchEvent.bind(this))
```

2. 通过[onTouch](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch#ontouch)事件处理触摸操作。TouchType.Move事件中，计算手指相对于摇杆中心的位置，并更新小圆圈的位置。同时，计算出手指与中心点连线的角度和距离，用于控制物体的移动方向和速度。TouchType.Up事件中，停止物体的移动，并将小圆圈复位到摇杆的中心。
```text
<em>// </em><em>处理手指移动的事件</em>
handleTouchEvent(event: TouchEvent) {
  switch (event.type) {
    case TouchType.Down:
    <em>  // 开始定时任务</em>
      this.taskId = setInterval(() => {
        this.personX += this.speed * this.cos;
        this.personY += this.speed * this.sin;
      }, 40);
      break;
    case TouchType.Move:
     <em> // 获取手指位置坐标</em>
      let x = event.touches[0].x;
      let y = event.touches[0].y;
     <em> // 计算手指与中心点的坐标差值</em>
      let vx = x - this.centerX;
      let vy = y - this.centerY;
   <em>   // 计算手指与中心点连线和x轴正半轴的夹角，单位是弧度</em>
      let angle = Math.atan2(vy, vx);
      this.sin = Math.sin(angle);
      this.cos = Math.cos(angle);
     <em> // 计算手指与中心点的距离</em>
      let distance = this.getDistance(vx, vy);
      this.getUIContext()?.animateTo(
        { curve: curves.responsiveSpringMotion() },
        () => {
         <em> // 计算摇杆小球的坐标</em>
          this.positionX = this.centerX + distance * this.cos;
          this.positionY = this.centerY + distance * this.sin;
          <em>// </em><em>弧度换算角度</em>
          this.angle = angle * 180 / Math.PI;
          this.speed = 5;
        }
      );
      break;
    case TouchType.Up:
     <em> // 还原物体速度</em>
      this.speed = 0;
      <em>// </em><em>取消定时任务</em>
      clearInterval(this.taskId);
     <em> // 还原摇杆小球的坐标</em>
      this.getUIContext()?.animateTo(
        { curve: curves.springMotion() },
        () => {
          this.positionX = this.centerX;
          this.positionY = this.centerY;
        }
      );
      break;
  }
}
```

3. 设置动画效果。
通过animateTo方法来平滑地改变物体的位置和摇杆小圆圈的位置。使用responsiveSpringMotion和springMotion方法来实现弹簧动画效果，使移动更加自然。
```text
this.getUIContext()?.animateTo(
  { curve: curves.responsiveSpringMotion() },
  () => {
   <em> // 计算摇杆小球的坐标</em>
    this.positionX = this.centerX + distance * this.cos;
    this.positionY = this.centerY + distance * this.sin;
   <em> // 弧度换算角度</em>
    this.angle = angle * 180 / Math.PI;
    this.speed = 5;
  }
);
```
 
```text
<em>// </em><em>还原摇杆小球的坐标</em>
this.getUIContext()?.animateTo(
  { curve: curves.springMotion() },
  () => {
    this.positionX = this.centerX;
    this.positionY = this.centerY;
  }
);
```

4. 通过[TransitionEffect](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-component#transitioneffect10对象说明)中的combine和animation方法来实现组合动画。
```text
<em>// </em><em>物体图片</em>
Image(this.src)
  .position({ x: this.personX - 20, y: this.personY - 20 })
  .rotate({ angle: this.angle })
  .transition(TransitionEffect.OPACITY.animation({ duration: 1000 }).combine(
    TransitionEffect.translate({ x: -240 })
  ))
  .width(40)
  .height(40)
```

5. 完整示例参考如下：
```text
import curves from '@ohos.curves';

@Entry
@Component
struct AnimationPageDemo {
 <em> // 物体坐标</em>
  @State personX: number = 200;
  @State personY: number = 120;
 <em> // 物体角度</em>
  @State angle: number = 0;
  <em>// 物体图片</em>
  @State src: Resource = $r('app.media.startIcon');
  <em>// </em><em>是否开始游戏</em>
  @State isBegin: boolean = false;
<em>  // 角度正弦和余弦</em>
  sin: number = 0;
  cos: number = 0;
 <em> // 物体移动速度</em>
  speed: number = 0;
 <em> // 任务id</em>
  taskId: number = -1;
  <em>// 摇杆中心区域坐标</em>
  private centerX: number = 120;
 <em> // 摇杆小圆球初始位置</em>
  @State positionX: number = this.centerX;
  private centerY: number = 120;
  @State positionY: number = this.centerY;
  <em>// </em><em>大、小圆半径</em>
  private maxRadius: number = 100;
  private radius: number = 20;

  build() {
    Row() {
      Stack() {
        <em>// 开始按钮和物体</em>
        if (!this.isBegin) {
        <em>  // 开始按钮</em>
          Button('开始游戏')
            .onClick(() => {
              this.getUIContext()?.animateTo(
                { duration: 1000 },
                () => {
                 <em> // 点击后显示物体</em>
                  this.isBegin = true;
                }
              );
            });
        } else {
        <em>  // 物体图片</em>
          Image(this.src)
            .position({ x: this.personX - 20, y: this.personY - 20 })
            .rotate({ angle: this.angle })
            .transition(TransitionEffect.OPACITY.animation({ duration: 1000 }).combine(
              TransitionEffect.translate({ x: -240 })
            ))
            .width(40)
            .height(40)
        }
       <em> // 摇杆</em>
        Row() {
          Circle({ width: this.maxRadius * 2, height: this.maxRadius * 2 })
            .fill('#20101010')
            .position({ x: this.centerX - this.maxRadius, y: this.centerY - this.maxRadius })
          Circle({ width: this.radius * 2, height: this.radius * 2 })
            .fill('#403A3A3A')
            .position({ x: this.positionX - this.radius, y: this.positionY - this.radius })
        }
        .height(240)
        .width(240)
        .justifyContent(FlexAlign.Center)
        .position({ x: 0, y: 120 })
        .onTouch(this.handleTouchEvent.bind(this))
      }
      .height('100%').width('100%')
    }
    .height('100%')
    .width('100%')
  }
 <em> // 处理手指移动的事件</em>
  handleTouchEvent(event: TouchEvent) {
    switch (event.type) {
      case TouchType.Down:
       <em> // 开始定时任务</em>
        this.taskId = setInterval(() => {
          this.personX += this.speed * this.cos;
          this.personY += this.speed * this.sin;
        }, 40);
        break;
      case TouchType.Move:
      <em>  // 获取手指位置坐标</em>
        let x = event.touches[0].x;
        let y = event.touches[0].y;
       <em> // 计算手指与中心点的坐标差值</em>
        let vx = x - this.centerX;
        let vy = y - this.centerY;
     <em>   // 计算手指与中心点连线和x轴正半轴的夹角，单位是弧度</em>
        let angle = Math.atan2(vy, vx);
        this.sin = Math.sin(angle);
        this.cos = Math.cos(angle);
     <em>   // 计算手指与中心点的距离</em>
        let distance = this.getDistance(vx, vy);
        this.getUIContext()?.animateTo(
          { curve: curves.responsiveSpringMotion() },
          () => {
          <em>  // 计算摇杆小球的坐标</em>
            this.positionX = this.centerX + distance * this.cos;
            this.positionY = this.centerY + distance * this.sin;
          <em>  // 弧度换算角度</em>
            this.angle = angle * 180 / Math.PI;
            this.speed = 5;
          }
        );
        break;
      case TouchType.Up:
      <em>  // 还原物体速度</em>
        this.speed = 0;
       <em> // 取消定时任务</em>
        clearInterval(this.taskId);
       <em> // 还原摇杆小球的坐标</em>
        this.getUIContext()?.animateTo(
          { curve: curves.springMotion() },
          () => {
            this.positionX = this.centerX;
            this.positionY = this.centerY;
          }
        );
        break;
    }
  }
  getDistance(x: number, y: number) {
    let d = Math.sqrt(x * x + y * y);
    return Math.min(d, this.maxRadius);
  }
}
```
