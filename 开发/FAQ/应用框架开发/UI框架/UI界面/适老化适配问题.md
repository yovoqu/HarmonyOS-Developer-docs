# 适老化适配问题

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1205

#### 问题现象

在实现适老化功能时，有以下经典场景：
 
- 场景一：标准字体大小为24px，放大六档后，字体大小是多少，是按照倍数去放大吗？
- 场景二：关怀模式调整放大倍率后，应用内组件未放大，该如何修改？
- 场景三：如何实现在系统不设置适老化场景情况下，应用内自实现适老化，只开启应用内适老化场景时，只有应用内进行统一放大显示，不影响系统和其他应用？
- 场景四：TextArea的滚动条能否隐藏？
- 场景五：在实现主题切换和适老化模式切换能力的过程中，针对每个UI组件做配置时，无法实现切换状态后实时更新UI组件的样式配置，有无简便方式实现？

 
 

#### 背景知识

- [setCustomDensity](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-windowstage#setcustomdensity20)：支持应用主窗口自定义显示大小缩放系数，并设置已创建的子窗和系统窗口跟随主窗重新布局的生效时机。当存在同时使用该接口和[setDefaultDensityEnabled(true)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-windowstage#setdefaultdensityenabled12)的情况时，以最后调用的设置效果为准。
- [BarState](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-appendix-enums#barstate)：用于设置滚动条的状态。
- [TextArea](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-textarea)：多行文本输入框组件，当输入的文本内容超过组件宽度时会自动换行显示。
- [maxFontScale](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-textarea#maxfontscale18)：设置文本最大的字体缩放倍数。

 
 

#### 解决方案

- 场景一：标准字体大小为24px，放大六档后的字体大小是放大3.2倍也就是24px * 3.2 ≈ 76.8px，系统字体被放大后，有界面布局异常的风险，为了确保应用整体布局不出现错乱，组件不出现重叠，在适老化指南中推荐根据业务需要，限制跟随字体最大档位、改变布局来更好的适配更大字体。详情请参考官网：[支持适老化](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkui-support-for-aging-adaptation)。
- 场景二：在app.json5中添加配置项configuration，并在base文件目录下新增profile文件夹，并在此目录下新增configuration.json文件。具体可参考[应用适配适老化大字体](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkui-support-for-aging-adaptation#应用适配适老化大字体)。
- 场景三：请参考官方文档接口[setCustomDensity](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-windowstage#setcustomdensity20)，支持应用主窗口自定义显示大小缩放系数，并设置已创建的子窗和系统窗口跟随主窗重新布局的生效时机。
- 场景四：TextArea中的[BarState](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-appendix-enums#barstate)可以设置输入框滚动条的显示模式。
- 场景五：做两套UI样式，结合首选项去记录当前是正常模式还是长者模式，根据需要切换对应的UI样式。使用Toggle控件开启、关闭“大字号模式”，并使用dataPreferences持久化用户的设置。请参考如下示例代码：

 
```json
import dataPreferences from '@ohos.data.preferences';

let preferences: dataPreferences.Preferences | null = null;
let options: dataPreferences.Options = { name: 'myStore' };

@Entry
@Component
struct AgeFriendly {
  <em>// 获取当前组件的上下文（用于访问数据存储等系统服务）</em>
  context: Context | undefined = this.getUIContext().getHostContext();
  @State isOn: boolean = false;
  @State customSize: string = '18vp';

  <em>// 生命周期钩子：在组件即将显示前执行（通常用于初始化数据）</em>
  aboutToAppear(): void {
    preferences = dataPreferences.getPreferencesSync(this.context, options);
    if (!preferences) {
      return;
    }
    <em>// 从本地存储中读取 'customSize' 的值，若不存在则使用默认值 '18vp'</em>
    let customSize = preferences.getSync('customSize', '18vp');
    let isOn = preferences.getSync('isOn', 'false');
    console.info('The size value is' + customSize + '| isOn: ' + isOn);
    this.isOn = JSON.parse(isOn as string);
    this.customSize = customSize.toString();
  }

  build() {
    Column() {
      Text('点击按钮切换长者模式')
        .fontSize(this.customSize)
        .fontColor(Color.Black);

      Row() {
        <em>// Toggle 开关控件：用于开启/关闭长者模式</em>
        Toggle({
          type: ToggleType.Switch, <em>// type: Switch 表示显示为滑动开关样式</em>
          isOn: this.isOn <em>// isOn: 绑定响应式状态变量，开关状态实时同步</em>
        })
          .selectedColor('#007DFF')
          .switchPointColor('#FFFFFF')
          .onChange((isOn: boolean) => {
            <em>// 当开关状态改变时触发的回调函数</em>
            this.isOn = isOn; <em>// 更新本地状态变量</em>
            this.customSize = isOn ? '28vp' : '18vp'; <em>// 根据状态切换字体大小</em>
            if (!preferences) {
              return;
            }
            <em>// 根据开关状态写入新的字体大小值</em>
            if (isOn) {
              preferences.putSync('customSize', '28vp');
              preferences.putSync('isOn', 'true');
            } else {
              preferences.putSync('customSize', '18vp');
              preferences.putSync('isOn', 'false');
            }
            <em>// 强制将所有未写入的数据立即刷新到磁盘（确保持久化生效）</em>
            preferences.flush();
          });
      };
    }
    .justifyContent(FlexAlign.Center)
    .alignItems(HorizontalAlign.Center)
    .width('100%')
    .height('100%');
  }
}
```
