# 如何结合关键帧动画和路径动画绘制

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1182

#### 问题现象

在关键帧动画中的不同步骤如何使用不同motionPath路径？
 
 

#### 背景知识

- 使用[keyframeAnimateTo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-keyframeanimateto)可以指定若干个关键帧状态，实现分段的动画。
- 使用[motionPath](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-motion-path-animation)可以设置组件进行位移动画时的运动路径。
- [绘制路径](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ui-js-components-svg-path)格式要求：必须符合SVG路径规范，使用M（移动）、L（直线）、C（贝塞尔曲线）等指令。

 
 

#### 解决方案

在keyframeAnimateTo中分段设置motionPath会导致路径移动异常，可以使用显示动画配合onFinish回调方法实现分段路径，具体实现如下：
