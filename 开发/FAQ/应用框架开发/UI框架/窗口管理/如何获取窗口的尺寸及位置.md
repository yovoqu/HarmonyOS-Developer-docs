# 如何获取窗口的尺寸及位置

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1023

#### 问题现象

应用开发过程中，窗口的尺寸及位置该如何获取？
 
 

#### 背景知识

- [getWindowProperties](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-window#getwindowproperties9)接口可以获取当前窗口的属性，该接口返回的[WindowProperties](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-i#windowproperties)实例中的windowRect属性返回一个[Rect](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-i#rect7)类型的参数，该参数可获取到当前窗口的宽度（width）和高度（height）及窗口的左边界（left）和上边界（top）信息。
- [OH_WindowManager_GetWindowProperties](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-oh-window-h#oh_windowmanager_getwindowproperties)：HarmonyOS Next提供了Native侧获取窗口属性的napi，该接口返回的[WindowManager_WindowProperties](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-windowmanager-windowproperties)实例中的windowRect属性返回一个[WindowManager_Rect](https://lfwiseopertest04.hwcloudtest.cn/knowledge-admin/knowledgeDetail/(https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-windowmanager-rect))类型的参数，该参数可获取到当前窗口的宽度（width）和高度（height）及窗口的x轴（posX）和y轴（posY）的信息。

 
 

#### 解决方案
