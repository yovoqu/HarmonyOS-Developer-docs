# 视频下方的列表刷新，视频同步发生刷新，刷新异常

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-541

#### 问题现象

视频下方的列表下拉刷新时，列表上方的视频也会进行刷新。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/7C6diobORW2E1zTRqEq31w/zh-cn_image_0000002658790881.png?HW-CC-KV=V1&HW-CC-Date=20260730T072318Z&HW-CC-Expire=86400&HW-CC-Sign=CB6DFCCF0599542F480CA39B0A069C284B47B168F62912BE5909ACF973DC04FA)

 
 

#### 背景知识

- 下拉刷新效果可通过如下方式实现：[Refresh](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-refresh)组件可以进行页面下拉操作并显示刷新动效，并通过[onRefreshing](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-refresh#onrefreshing)方法在进入刷新状态时触发回调。
- [Video](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-media-components-video)为用于播放视频文件并控制其播放状态的组件。

#### 分析结论

视频组件播放视频列表中的第一个视频，视频列表下拉刷新时视频数据重新加载，加载完成后视频组件重新获取视频列表中的第一个视频，导致刷新。
 
 

#### 修改建议

视频列表下拉刷新视频数据重新加载后，判断加载后的视频资源与原先的资源是否是相同的，不相同时再重新加载视频。
 
关键部分：
 
```text
Stack() {
  Video({
    src: $rawfile(this.currentSec),
    controller: this.controller
  })
```
 
```text
.onRefreshing(() => {
 <em> // 模拟数据刷新。</em>
  setTimeout(() => {
    this.refreshing = false;
    this.videos = [new MyVideo('video1.mp4', $r('app.media.myposter1')),
      new MyVideo('video1.mp4', $r('app.media.myposter2'))];
   <em> // 判断刷新后的视频资源是否是原先资源</em>
    if (this.videos[0].src !== this.currentSec) {
      this.currentSec = this.videos[0].src; <em>// 重新加载视频</em>
      console.info('currentSec', this.currentSec.toString());
      this.controller.setCurrentTime(this.currentTime);
    }
  }, 500);
})
```
