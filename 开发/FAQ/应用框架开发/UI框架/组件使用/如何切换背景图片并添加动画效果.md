# 如何切换背景图片并添加动画效果

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-749

#### 问题现象

使用backgroundImage时，如何切换背景图片并添加动画效果。
 
 

#### 背景知识

- [backgroundImage](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-background#backgroundimage)：该属性为组件通用属性，可以设置组件的背景图片，且是可动画的属性。
- [animateTo](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-uicontext#animateto)：用来指定由于闭包代码导致的状态变化插入过渡动效，修改可动画的属性时可以实现动画效果。
- [Image](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image)：图片组件，常用于在应用中显示图片。Image支持加载PixelMap、ResourceStr和DrawableDescriptor类型的数据源，支持png、jpg、jpeg、bmp、svg、webp、gif和heif类型的图片格式。

 
 

#### 解决方案

- **方案一**：定义状态变量，改变其值来切换背景，使用animateTo属性为背景图片的切换添加动画效果。
```text
@Entry
@Component
struct BackgroundChangePage {
  @State backgroundImageSrc: ResourceStr = $r('app.media.background');<em> </em><em>// background.png可替换为media目录下的图片</em>
  @State opacityValue: number = 1;
  @State isAnimating: boolean = false;

  handleButtonClick() {
    if (this.isAnimating) {
      return;
    }
    this.isAnimating = true;
   <em> // 第一步：淡出动画</em>
    this.getUIContext()?.animateTo({
      duration: 500,
      curve: Curve.EaseOut
    }, () => {
      this.opacityValue = 0;
    });
   <em> // 第二步：切换图片后淡入</em>
    setTimeout(() => {
      this.backgroundImageSrc = $r('app.media.startIcon'); <em>// startIcon.png</em><em>可替换为media目录下的图片</em>
      this.getUIContext()?.animateTo({
        duration: 600,
        curve: Curve.EaseIn,
        onFinish: () => {
          this.isAnimating = false;
        }
      }, () => {
        this.opacityValue = 1;
      });
    }, 500);
  }

  build() {
    Column({ space: 10 }) {
      Text('My Text')
        .width('90%')
        .height('90%')
        .fontSize(20)
        .fontColor(Color.White)
        .textAlign(TextAlign.Center)
        .backgroundImage(this.backgroundImageSrc)
        .backgroundImageSize(ImageSize.Cover)
        .opacity(this.opacityValue);
      Button('Toggle Background')
        .onClick(() => this.handleButtonClick());
    }
    .width('100%')
    .height('50%')
    .margin({ top: 20 });
  }
}
```

- **方案二**：使用Image组件代替backgroundImage属性，通过改变其src并添加过渡动画来实现。
```text
@Entry
@Component
struct ImageChangePage {
  @State currentBg: Resource = $r('app.media.background');<em> </em><em>// background.png可替换为media目录下的图片</em>
  @State opacityValue: number = 1;

  changeBackground() {
  <em>  // 第一步：淡出动画</em>
    this.getUIContext()?.animateTo({
      duration: 500,
      curve: Curve.EaseOut,
    }, () => {
      this.opacityValue = 0;
    });
    <em>// </em><em>第二步：切换图片后淡入</em>
    setTimeout(() => {
      this.currentBg = $r('app.media.startIcon'); <em>// startIcon.png</em><em>可替换为media目录下的图片</em>
      this.getUIContext()?.animateTo({
        duration: 500,
        curve: Curve.EaseIn,
      }, () => {
        this.opacityValue = 1;
      });
    }, 500);
  }

  build() {
    Stack({ alignContent: Alignment.Center }) {
    <em>  // 背景图片，使用Image组件填充整个屏幕</em>
      Image(this.currentBg)
        .width('100%')
        .height('100%')
        .objectFit(ImageFit.Cover)
        .opacity(this.opacityValue);
      Button('切换背景')
        .margin(20)
        .onClick(() => {
          this.changeBackground();
        });
    }
    .width('100%')
    .height('100%');
  }
}
```
