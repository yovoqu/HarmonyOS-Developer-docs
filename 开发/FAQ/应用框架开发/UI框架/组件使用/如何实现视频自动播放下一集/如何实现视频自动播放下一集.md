# 如何实现视频自动播放下一集

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1478

#### 问题现象

如何实现当前视频播放完之后自动播放下条视频。

#### 背景知识

- [Video组件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-common-components-video-player)用于播放视频文件并控制其播放状态，常用于短视频和应用内部视频的列表页面。
- [Swiper组件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-layout-development-create-looping)提供滑动轮播显示的能力，可以用于实现短视频切换功能。

 
 

#### 解决方案

实现思路如下：
 1. 整体架构：使用Swiper嵌套Video组件实现短视频播放功能主体。
2. 视频播放完成后自动跳转下条视频：可以通过调用Swiper组件的[showNext](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-swiper#shownext)事件主动跳转下一页。
3. 页面切换后视频自动播放：Swiper组件切换页面时则会触发[onChange](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-swiper#onchange)回调，可以在该回调中调用Video组件的[start](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-media-components-video#start)事件开启视频播放。
 
完整示例代码如下：
 
```text
class VideoClass { <em>// 创建视频类</em>
  controller: VideoController = new VideoController();
  videoSrc: Resource = $rawfile('videoTest.mp4');
}

@Entry
@Component
struct VideoAutomaticallyPlays {
  private swiperController: SwiperController = new SwiperController();
  private videoList: Array<VideoClass> = [];
  @State isShow: boolean = true;<em> // 控制暂停按键的显隐</em>
  @State lastShow: number = 0;

  aboutToAppear(): void {
    for (let i = 0; i < 10; i++) {
      this.videoList.push(new VideoClass()); <em>// 创建视频实例</em>
    }
  }

  build() {
    Column() {
      Swiper(this.swiperController) {
        ForEach(this.videoList, (item: VideoClass) => {
          Stack() {
            Video({
              src: item.videoSrc,
              controller: item.controller
            })
              .height('100%')
              .width('100%')
              .controls(false)<em> // 关闭视频控制栏</em>
              .onFinish(() => {
                this.swiperController.showNext();<em> // 跳转下个视频</em>
              });
            Row() {
              Column() {
                Text('@XXX')
                  .fontColor(Color.White);
              }
              .height('100%')
              .justifyContent(FlexAlign.End)
              .padding({
                bottom: 60
              });

              Column({ space: 40 }) {
                Image($r('app.media.love'))
                  .width(30)
                  .height(30);
                Image($r('app.media.comment'))
                  .width(30)
                  .height(30);
                Image($r('app.media.share'))
                  .width(30)
                  .height(30);
              }
              .height('100%')
              .justifyContent(FlexAlign.End)
              .padding({
                bottom: 150
              });
            }
            .width('100%')
            .height('100%')
            .justifyContent(FlexAlign.SpaceBetween)
            .padding({
              left: 20,
              right: 20
            });

            Image($r('app.media.play'))
              .width(30)
              .height(30)
              .visibility(this.isShow ? Visibility.Visible : Visibility.None);<em> // 是否显示暂停图标</em>
          }
          .onClick(() => {<em> // 点击切换视频播放状态</em>
            if (this.isShow) {
              item.controller.start();<em> // 开始播放</em>
            } else {
              item.controller.pause();<em> // 暂停播放</em>
            }
            this.isShow = !this.isShow;
          });
        });
      }
      .width('100%')
      .height('100%')
      .indicator(false)
      .vertical(true)
      .loop(false)
      .autoPlay(false)
      .onChange((index: number) => {<em> // 页面切换时触发的回调</em>
        this.videoList[this.lastShow].controller.stop();
        this.videoList[index].controller.start();<em> // 启动视频播放</em>
        this.lastShow = index;
        this.isShow = false;
      });
    }
    .width('100%')
    .height('100%')
    .justifyContent(FlexAlign.Center);
  }
}
```
