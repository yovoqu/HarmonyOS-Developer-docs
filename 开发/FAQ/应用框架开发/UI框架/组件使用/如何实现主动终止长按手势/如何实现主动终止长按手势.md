# 如何实现主动终止长按手势

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1462

#### 问题现象

通过GestureGroup实现了长按录音的功能，现在需要录音超过60秒停止识别，如何实现主动终止长按手势？
 
 

#### 背景知识

[LongPressGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-longpressgesture)，用于触发长按手势事件，触发长按手势的最少手指数为1，最短长按时间为500毫秒。
 
 

#### 解决方案

在HarmonyOS开发中，可通过状态管理结合定时器机制实现长按手势在60秒后主动终止。通过LongPressGesture的onAction回调启动定时器，结合状态变量控制手势终止逻辑：
 1. 启动长按时触发定时器，60秒后修改状态。
2. 在手势回调中判断状态以终止逻辑。
3. 通过onActionEnd清理定时器。
 
```text
@Component
@Entry
struct PressGestureDemo {
  @State isLongPressActive: boolean = true;<em> </em><em>// 控制手势激活状态</em>
  private timerId: number = 0;<em> </em><em>// 存储定时器ID</em>

  build() {
    Row() {
      Column() {
        Button('长按60秒后自动终止')
          .gesture(
            LongPressGesture({ duration: 500 })
              .onAction(() => {
                if (!this.isLongPressActive) {
                  return;
                } <em>// 状态终止时退出</em>
               <em> // 启动60秒定时器</em>
                this.timerId = setTimeout(() => {
                  this.isLongPressActive = false;
               <em>   // 此处可添加终止后的业务逻辑，即终止录音操作</em>
                }, 60000);
              })
              .onActionEnd(() => {
                clearTimeout(this.timerId); <em>// </em><em>清理定时器</em>
                this.isLongPressActive = true;<em> </em><em>// 重置状态</em>
              })
          );
      }.width('100%');
    }.height('100%');
  }
}
```
