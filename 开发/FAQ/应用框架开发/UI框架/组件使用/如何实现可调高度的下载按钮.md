# 如何实现可调高度的下载按钮

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1551

#### 问题现象

ProgressButton默认不支持高度调整，如何实现可调高度的下载按钮？
 
 

#### 背景知识

[Progress](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-progress)：进度条组件，用于显示内容加载或操作处理等进度。
 
 

#### 解决方案

- 方案逻辑：Progress组件可以配置高度，使用Progress的属性可实现与ProgressButton相同的下载效果。1. 通过Progress组件的style属性的content参数，实现在Progress组件上显示按钮文字和进度信息。
