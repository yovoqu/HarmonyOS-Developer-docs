# 自定义组件拦截父组件的滚动

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1397

#### 问题现象

如何实现在特定区域滑动时，父组件Scroll不响应滚动？
 
 

#### 背景知识

- [Scroll](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scroll)、[Grid](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid)、[List](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-list)、[WaterFlow](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-waterflow)都是可滚动的容器组件，可通过滚动组件通用接口[enableScrollInteraction](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scrollable-common#enablescrollinteraction11)来设置组件是否支持滚动手势。
- [触摸事件onTouch](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch)是组件的通用事件，在手指触摸动作时触发该回调，回调入参包含以下信息：
触摸事件的类型TouchType，表示手指按下、抬起、滑动等信息。
- 屏幕触点的信息Array&lt;TouchObject&gt;，手指在屏幕上的坐标。

 - [gesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-gesture-settings#gesture)可以为组件绑定不同类型的手势事件，并设置事件的响应方法。

 
 

#### 解决方案

- **方案一**：触摸事件onTouch和滚动组件通用接口enableScrollInteraction配合实现。在特定区域滑动时，滚动组件不滚动，则需要使用onTouch监听特定区域的触摸事件，在回调中判断触摸事件类型，手指按下TouchType.Down或滑动TouchType.Move时通过enableScrollInteraction设置滚动组件不可滚动，手指抬起时设置滚动组件支持滚动手势。

- **方案二**：gesture手势事件。使用gesture给特定区域绑定滑动手势事件[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)，则手指在此区域滑动时，滑动事件不会传递至外层的滚动组件，即实现此区域滑动时，滚动组件不滚动的效果。

  大部分代码和方案一类似，只需将onTouch事件替换为gesture即可。
