# 如何实现从底部弹出自定义弹窗并根据手势下拉关闭

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1229

#### 问题现象

如何实现一个从底部弹出的自定义弹窗，并支持通过手势下拉来关闭该弹窗？

#### 背景知识

- [弹窗](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-dialog-overview)一般指打开应用时自动弹出或者用户行为操作时弹出的UI界面，用于短时间内展示用户需关注的信息或待处理的操作。
- [自定义弹窗 (CustomDialog)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-methods-custom-dialog-box)可用于广告、中奖、警告、软件更新等与用户交互响应操作。开发者可以通过[CustomDialogController](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-methods-custom-dialog-box#customdialogcontroller)类显示自定义弹出框。
- [触摸事件](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch)由手指在组件上按下、滑动或抬起时触发。[onTouch](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch#ontouch)是手指触摸动作触发的回调，可以获取触摸类型[TouchType](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-appendix-enums#touchtype)（按下、滑动、抬起等），以及触点信息[TouchObject](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-events-touch#touchobject)（类型、坐标、时间等）。
- [transition](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-component#transition)可用于设置组件插入显示和删除隐藏的过渡效果。

 
 

#### 解决方案

可以通过onTouch监听触摸事件，判断用户是否进行了下拉动作，然后使用transition实现弹窗的入场和出场动画，最后为了保证动画完整播放，关闭操作延迟执行。

#### 常见FAQ

Q：自定义组件添加[TransitionEffect](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-component#transitioneffect10对象说明).OPACITY进场出场动画，组件显示的颜色是否和透明度有关系？
 
A：为组件添加透明度转场效果，出现时透明度从0到1，消失时透明度从1到0，当完全透明的时候，显示的是组件自身的背景色。
