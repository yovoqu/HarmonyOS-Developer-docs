# 如何在H5中调用麦克风

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkweb-163

#### 问题现象

WebView网页端获取麦克风录音权限时，没有成功开启录音。
 
 

#### 背景知识

- [声明权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/declare-permissions)：应用在申请权限时，需要在项目的配置文件中，逐个声明需要的权限，否则应用将无法获取授权。
- [onPermissionRequest](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-basic-components-web-events#onpermissionrequest9)：通知收到获取权限请求，需配置"ohos.permission.CAMERA"、"ohos.permission.MICROPHONE"权限。

 
 

#### 解决方案
1. 在module.json5文件配置'ohos.permission.MICROPHONE'话筒权限。
```json

    <span style="color: rgb(132,63,161);">"requestPermissions"</span><span style="color: rgb(181,106,1);">:</span>[
      {
        <span style="color: rgb(132,63,161);">"name" </span><span style="color: rgb(181,106,1);">: </span><span style="color: rgb(80,160,79);">"ohos.permission.MICROPHONE"</span><span style="color: rgb(181,106,1);">,</span>
```
