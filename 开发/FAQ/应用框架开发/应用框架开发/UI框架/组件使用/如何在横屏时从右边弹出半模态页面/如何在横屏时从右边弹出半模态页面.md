# 如何在横屏时从右边弹出半模态页面

更新时间：2026-06-26 07:47:42

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-678

#### 问题现象

组件使用bindSheet属性绑定半模态页面，竖屏时，半模态页面从底部弹出，期望应用在横屏时，从右边弹出半模态页面。
 
 

#### 背景知识

通过[bindSheet](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-sheet-transition#bindsheet)属性为组件绑定半模态页面，在组件插入时可通过设置自定义或默认的内置高度确定半模态大小。点击后默认从底部弹出模态页面。
 
 

#### 解决方案
1. 半模态在竖屏时可以满足要求，但在横屏时不能从右边弹出，需要和自定义弹窗互相搭配使用。
2. 使用媒体查询接口监听屏幕旋转。在竖屏时弹窗弹出的是半模态弹窗，横屏后弹出的是自定义弹窗。代码运行前需要将[module.json5的orientation字段](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-landscape-and-portrait-development#section1188593118171)配置成auto_rotation,让屏幕随传感器旋转。
