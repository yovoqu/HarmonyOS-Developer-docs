# 如何实现评论输入框支持自定义表情展示

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-972

#### 问题现象

直播弹幕输入评论功能，在自定义键盘中使用TextArea不支持表情展示，用户体验不佳，希望实现底部模态弹窗评论输入框，支持自定义表情预览展示。
 
 

#### 背景知识

- [bindSheet](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-sheet-transition#bindsheet)：通过bindSheet属性为组件绑定半模态页面，在组件插入时可通过设置自定义或默认的内置高度确定半模态大小。
- [RichEditor](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-richeditor)：支持图文混排和文本交互式编辑的组件，其中可通过[addImageSpan](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-richeditor#addimagespan)添加图片内容。

 
 

#### 解决方案
1. 通过半模态弹窗实现自定义表情UI视图。
2. 使用RichEditor组件实现图文混排输入框功能。
3. 使用[focusControl.requestFocus](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-focus#requestfocus9)控制输入框获焦，获焦后半模态弹窗时软键盘会自动弹出。
4. 点击自定义表情时通过addImageSpan接口添加到输入框。
