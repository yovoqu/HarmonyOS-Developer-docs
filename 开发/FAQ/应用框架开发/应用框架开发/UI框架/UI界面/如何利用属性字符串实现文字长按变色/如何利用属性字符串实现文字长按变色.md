# 如何利用属性字符串实现文字长按变色

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1284

#### 问题现象

使用Text组件嵌套Span组件如何做到选中之后单独设置颜色，并且添加点击事件？
 
 

#### 背景知识

- [属性字符串](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-styled-string)是方便灵活应用文本样式的对象，可通过TextController中的[setStyledString](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-richeditor#setstyledstring12)方法与Text组件绑定。
- [replaceString](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-styled-string#replacestring)：可以替换指定范围的字符串。
