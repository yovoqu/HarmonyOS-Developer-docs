# 自定义嵌套弹窗统一关闭

更新时间：2026-06-26 09:07:13

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-arkui-1017

#### 问题现象

多个自定义嵌套弹窗，如何实现一键全部关闭。
 
 

#### 背景知识

- [自定义弹窗](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-methods-custom-dialog-box)：通过CustomDialogController类显示自定义弹窗。使用弹窗组件时，优先考虑自定义弹窗，便于弹窗样式与内容的自定义。
- [onCreate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-ability-abilitystage#oncreate)：当UIExtensionAbility组件实例完成创建时，系统会触发该回调。开发者可在该回调中执行初始化逻辑（如定义变量、加载资源等）。
- [AppStorage](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-appstorage)：AppStorage是与应用进程绑定的全局UI状态存储中心，由UI框架在应用启动时创建，将UI状态数据存储于运行内存，实现应用级全局状态共享。

 
 

#### 解决方案

通过HarmonyOS中的一个UIAbility类实现，使用AppStorage存储全局的弹窗控制器数组DialogList，实现跨页面、跨组件数据共享。并通过事件总线实现“添加弹窗”和“关闭所有弹窗”的跨组件通信。
