# 如何查看智能体AgentID

更新时间：2026-06-26 07:48:29

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-agent-framework-5

#### 问题现象

如何在小艺开放平台上查找已创建智能体的AgentID？
 
 

#### 解决方案

方法一：登录小艺开放平台后，点击已创建的智能体，在配置页面下可查找到智能体ID，即为该智能体的AgentID。
 

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/gmUWnLUASpuip52u6NMU5Q/zh-cn_image_0000002658914061.png?HW-CC-KV=V1&HW-CC-Date=20260730T072734Z&HW-CC-Expire=86400&HW-CC-Sign=BE9AD6874FB64563D29A0591D821B389F74E050C801C97CF06D522F995F6DEEF)

 
方法二：登录小艺开放平台后，点击已创建的智能体，在网页地址栏中存在"agentid=agentxxxx"样字段，即为该智能体AgentID，样例如下图所示：
