# 用户如何退出AppTest邀请测试

更新时间：2026-06-26 07:48:29（官网已下线）

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-appgallery-100

#### 问题现象

用户申请体验了AppTest邀请测试，现在想回退成AppGallery邀请测试，如何操作？
 
 

#### 解决方案

用户自己无法回退成AppGallery邀请测试，和申请AppTest邀请测试一样，可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/?channel=ICS0000)与我们联系回退成AppGallery邀请测试。
 
工单“问题分类”请选择“华为应用分发-应用市场-应用测试”，并在“问题描述”中提供您的开发者名称、开发者ID、应用名称、APP ID。
