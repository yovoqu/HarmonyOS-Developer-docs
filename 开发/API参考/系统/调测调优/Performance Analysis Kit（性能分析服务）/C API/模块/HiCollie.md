#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

提供检测业务线程卡死、卡顿，以及上报卡死事件的能力。本模块函数支持以下功能：
 
（1）注册应用业务线程卡死的周期性检测任务；
 
（2）注册应用业务线程卡顿检测的回调函数；
 
（3）上报应用业务线程卡死事件。
 
 使用场景：应用卡顿问题定位、线程健康状态监控、开发调试阶段的卡死问题诊断、卡顿数据采集与分析。
 
**起始版本：** 12
