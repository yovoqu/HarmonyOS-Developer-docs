#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

用于注册传感器数据订阅的订阅者信息结构体，包含订阅回调函数和用户数据。使用该结构体可以指定传感器订阅者的参数，订阅成功后，将接收传感器的数据更新。
 
**起始版本：** 11
