##### 1006100001 系统中断

**错误信息**
 
System Interruption.
 
**错误描述**
 
系统出现异常时，系统会产生此错误码。
 
**可能原因**
 
运行环境异常。
 
**处理步骤**
 
1 重启系统。
 
2 重试操作。
 
  

##### 1006100002 服务异常

**错误信息**
 
The service is abnormal.
 
**错误描述**
 
IFAA服务异常时，系统会产生此错误码。
 
**可能原因**
 
IFAA服务异常。
 
**处理步骤**
 
1 重试操作。
 
2 重启系统，重试操作。
