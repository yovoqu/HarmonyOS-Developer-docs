# GameController

更新时间：2026-07-28 11:23:46

来源：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-gamecontroller
**支持设备：** Phone | PC/2in1 | Tablet | TV

#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | TV

提供游戏控制器功能的API接口，支持游戏适配控制器外设，帮助实现游戏外设的上下线和按键及轴事件监听等功能。
 
**起始版本：** 21
 
  

#### 文件汇总

**支持设备：** Phone | PC/2in1 | Tablet | TV
 
| 名称 | 描述 |
| --- | --- |
| game_controller_type.h | 定义GameController模块的通用枚举类型。 |
| game_device.h | 定义游戏设备的接口。 |
| game_device_event.h | 定义游戏设备事件的接口。 |
| game_pad.h | 定义游戏手柄的接口。 |
| game_pad_event.h | 定义游戏手柄事件的接口。 |
