#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable

表示一个JavaScript CPU时间性能分析器。
 
**使用场景：** 分析JavaScript应用或模块的CPU使用情况，定位性能热点和性能瓶颈，优化JavaScript代码执行效率。
 
**功能特点：** 提供详细的CPU时间分析数据，支持函数级别的性能统计，可生成性能分析报告。
 
**系统能力：** SystemCapability.ArkCompiler.JSVM
 
**起始版本：** 12
