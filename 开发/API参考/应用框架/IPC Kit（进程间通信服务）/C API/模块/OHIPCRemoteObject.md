#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

OHIPCRemoteObject是IPC跨进程通信的核心对象，用于实现跨进程的远程方法调用和数据传输。
 
**系统能力：** SystemCapability.Communication.IPC.Core
 
**起始版本：** 12
