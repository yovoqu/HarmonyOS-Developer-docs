#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

在Native侧提供ArkUI的UI输入事件能力，用于获取并处理触控、鼠标、轴、按键等UI输入事件，适用于需要在C/C++层直接处理UI输入事件的场景。
 
**起始版本：** 12
