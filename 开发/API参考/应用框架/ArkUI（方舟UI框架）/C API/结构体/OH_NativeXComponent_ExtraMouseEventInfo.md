#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

提供扩展鼠标事件信息的封装实例，用于在鼠标事件回调中获取标准鼠标事件之外额外的鼠标事件属性，适用于需要处理更丰富鼠标交互信息的应用场景。
