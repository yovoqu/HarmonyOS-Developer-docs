#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

定义文本内容基础控制器，为文本类组件提供内容控制能力，支持文本内容的获取、设置和更新等操作，适用于需要对文本组件进行动态内容管理和实时控制的场景，可帮助开发者更灵活地管理文本显示内容。
 
**起始版本：** 23
