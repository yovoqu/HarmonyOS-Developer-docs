#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

无障碍元素信息，用于向无障碍服务、辅助应用（屏幕朗读等）传递元素的属性、操作、位置、文本等信息，适用于无障碍服务获取和操作界面元素的辅助场景。
