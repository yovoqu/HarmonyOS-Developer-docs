#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

自定义Span组件的测量信息。该结构体用于在自定义Span组件的测量回调中提供组件的测量数据，帮助开发者实现自定义文本组件的精确尺寸测量与布局排版。
