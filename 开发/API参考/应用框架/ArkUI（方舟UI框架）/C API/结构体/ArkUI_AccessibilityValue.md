#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

定义组件的无障碍信息值，用于描述组件的无障碍状态，如范围类组件的最小值、最大值、当前值以及文本描述等，适用于需要向无障碍服务提供组件当前状态信息的场景。
 
**起始版本：** 12
