#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

定义文本输入框的计数器配置，用于管理字符计数。适用于需要对用户输入进行字符数限制与实时提示的场景，帮助用户了解输入进度，防止超出字符限制。
 
**起始版本：** 22
