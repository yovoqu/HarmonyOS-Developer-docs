#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

ArkUI_UIInputEvent用于表示ArkUI中的UI输入事件。ArkUI_EventModule中的事件接口通过该对象向回调传递输入事件数据，开发者可使用查询接口获取事件信息，适用于识别或响应用户输入事件的场景。
 
**起始版本：** 12
