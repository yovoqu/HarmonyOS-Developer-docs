#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

定义组件绘制上下文的结构体类型，用于在自定义组件绘制过程中提供绘制上下文信息，可获取用于绘制的 Canvas 指针和可绘制区域大小。
