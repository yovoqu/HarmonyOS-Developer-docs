#### 概述

**支持设备：** Phone | PC/2in1 | Tablet | Wearable | TV

设置拖拽跟手图的自定义参数（如投影、圆角效果等），用于在拖拽场景中自定义预览图显示效果，帮助应用提供更符合业务需求的拖拽交互体验。
